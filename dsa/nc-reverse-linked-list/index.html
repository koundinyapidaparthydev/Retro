Reverse Linked List

CORE

The problem they give you

They will not say “Reverse Linked List.” They describe this:

Given: The head of a singly linked list.

Find: Reverse the list and return the new head.

Tiny example: 1 → 2 → 3 → 4 → 5 becomes 5 → 4 → 3 → 2 → 1.

Run it in Java

Left is the snippet. Right is the output — one System.out.println at a time.

prev / curr / next

// 1 -> 2 -> 3
int[] vals = {1, 2, 3};
Integer prev = null;
for (int v : vals) {
  System.out.println("curr=" + v + " prev=" + prev);
  prev = v; // stand-in: after loop list is reversed conceptually
}
System.out.println("new head " + vals[vals.length - 1]);
