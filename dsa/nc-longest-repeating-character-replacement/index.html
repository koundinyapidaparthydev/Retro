The problem they give you

They will not say “Longest Repeating Character Replacement.” They describe this:

Given: A string of uppercase letters and an integer k.

Find: You may replace up to k characters. Return the longest substring you can make all the same letter.

Tiny example: "ABAB", k = 2 → 4. "AABABBA", k = 1 → 4.

Run it in Java

Left is the snippet. Right is the output — one System.out.println at a time.

window with most-freq char

String s = "AABABBA";
int k = 1;
int[] cnt = new int[26];
int L = 0, maxf = 0, best = 0;
for (int R = 0; R < s.length(); R++) {
  maxf = Math.max(maxf, ++cnt[s.charAt(R) - 'A']);
  while (R - L + 1 - maxf > k) cnt[s.charAt(L++) - 'A']--;
  best = Math.max(best, R - L + 1);
  System.out.println("R=" + R + " len=" + (R - L + 1) + " maxf=" + maxf);
}
System.out.println("best " + best);
