Morris Traversal

ADV

Definition

Thread a temporary link from a node's inorder predecessor to itself so you can walk the tree with O(1) extra memory, then unthread.

Why it exists

Morris is the 'do it in O(1) space' follow-up to inorder / flatten / recover-BST.

Approach

  1. cur = root.
  2. Else pred = cur.left; while pred.right && pred.right !== cur, pred = pred.right.
  3. If pred.right is null: pred.right = cur; cur = cur.left.
Time O(n)Space O(1) extra

Morris Traversal

cur = root. while cur: if !cur.left, visit cur, cur = cur.right.

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

thread the predecessor, then unthread

const n = (val, left = null, right = null) => ({ val, left, right });
const root = n(2, n(1), n(3));
const out = [];
let cur = root;

while (cur) {
  if (!cur.left) {
    out.push(cur.val);
    console.log("visit", cur.val);
    cur = cur.right;
    continue;
  }
  let pred = cur.left;
  while (pred.right && pred.right !== cur) pred = pred.right;
  if (!pred.right) {
    pred.right = cur;
    console.log("thread", pred.val, "→", cur.val);
    cur = cur.left;
  } else {
    pred.right = null;
    out.push(cur.val);
    console.log("unthread, visit", cur.val);
    cur = cur.right;
  }
}

More notes if you want them

Morris is the 'do it in O(1) space' follow-up to inorder / flatten / recover-BST. You should be able to explain the predecessor thread even if you need a minute to write it. It shows you understand that extra space in traversals is usually the stack of parent pointers, which you can encode in unused right links of leaves.

Use when: Inorder or preorder with O(1) extra space and a mutable tree you will restore.

Skip when: You may use O(h) stack — write the normal iterative traversal. It is clearer and safer.

Trap: Forgetting to unthread — the tree stays cyclic and later DFS infinite-loops.
