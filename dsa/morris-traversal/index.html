Morris Traversal

ADV

The problem they give you

They will not say “Morris Traversal.” They describe this:

Given: A binary tree. You may not use recursion or an explicit stack. You may temporarily write a child pointer if you put it back.

Find: The left-node-right visit order, using only a handful of pointers. The tree must look unchanged when you finish.

Tiny example: 1 with left 2 (4, 5) and right 3 → [4, 2, 5, 1, 3].

Name of the tool

Thread a temporary link from a node's inorder predecessor to itself so you can walk the tree with O(1) extra memory, then unthread.

Why this tool

Morris is the 'do it in O(1) space' follow-up to inorder / flatten / recover-BST.

Approach

  1. cur = root.
  2. Else pred = cur.left; while pred.right && pred.right !== cur, pred = pred.right.
  3. If pred.right is null: pred.right = cur; cur = cur.left.

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Left-node-right with O(1) extra memory.
  • You borrowed a right pointer as a return ticket. When do you cut it?
  • Visit on the first pass instead, and you have node-first order.

You say this first

Thread a temporary link from a node's inorder predecessor to itself so you can walk the tree with O(1) extra memory, then unthread. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n) time, O(1) extra space).

Offer the next notch: Else pred = cur.left; while pred.right && pred.right !== cur, pred = pred.right.. Tradeoff: You may use O(h) stack — write the normal iterative traversal. It is clearer and safer. Name predecessor threading first. If time is short, write iterative stack and say Morris is the O(1) version.

More notes if you want them

Morris is the 'do it in O(1) space' follow-up to inorder / flatten / recover-BST. You should be able to explain the predecessor thread even if you need a minute to write it. It shows you understand that extra space in traversals is usually the stack of parent pointers, which you can encode in unused right links of leaves.

Use when: Inorder or preorder with O(1) extra space and a mutable tree you will restore.

Skip when: You may use O(h) stack — write the normal iterative traversal. It is clearer and safer.

Trap: Forgetting to unthread — the tree stays cyclic and later DFS infinite-loops.
