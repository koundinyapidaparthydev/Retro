The problem they give you

They will not say “Candy Distribution.” They describe this:

Given: Children in a line, each with a rating. A child with a strictly higher rating than a neighbor must get more candies. Everyone gets at least 1.

Find: Minimum total candies.

Tiny example: Ratings [1,0,2] → 2,1,2. Total 5. [1,2,87,1] the peak needs more than both slopes.

Name of the tool

Give children candies so neighbors with a higher rating get more. Two passes (up the slopes, then down) or a one-array peak-and-valley fill. Greedy local slopes are enough.

Why this tool

Candy is the two-pass greedy that people try to solve with a single forward scan and fail on a decreasing slope.

Approach

  1. c[i]=1 for all i.
  2. for i=1..n-1: if r[i]>r[i-1] c[i]=c[i-1]+1.
  3. for i=n-2..0: if r[i]>r[i+1] c[i]=max(c[i], c[i+1]+1).

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

two slopes: left-to-right then right-to-left

const r = [1, 0, 2];
const c = r.map(() => 1);

for (let i = 1; i < r.length; i++) {
  if (r[i] > r[i - 1]) c[i] = c[i - 1] + 1;
}
console.log("after L→R", [...c]);

for (let i = r.length - 2; i >= 0; i--) {
  if (r[i] > r[i + 1]) c[i] = Math.max(c[i], c[i + 1] + 1);
}
console.log("after R→L", [...c]);
console.log("total", c.reduce((a, b) => a + b));

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Min candies.
  • Equal ratings have no extra rule between them.
  • One forward pass is not enough on a down-slope. Why?

You say this first

Give children candies so neighbors with a higher rating get more. Two passes (up the slopes, then down) or a one-array peak-and-valley fill. Greedy local slopes are enough. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n) time, O(n) space).

Offer the next notch: for i=1..n-1: if r[i]>r[i-1] c[i]=c[i-1]+1.. Tradeoff: Global ranking (kth gets more than everyone below) — just sort. Draw 1,3,2 and show why one forward pass assigns 1,2,1 and then the backward pass lifts the peak to 2 — wait, 1,2,1 already works. Use 1,2,87,1 or 1,3,2,2 to show the backward lift.

More notes if you want them

Candy is the two-pass greedy that people try to solve with a single forward scan and fail on a decreasing slope. The rating constraint is local (only neighbors) but the global min assignment needs both directions. Interviewers like it because the proof is 'satisfy left constraints, then right, take max.' Assign cookies is the easier sibling.

Use when: Neighbor inequality assignments on a line; rating/candy, similar 'strictly more than neighbor' problems.

Skip when: Global ranking (kth gets more than everyone below) — just sort.

Trap: Using = instead of max on the backward pass and wrecking the left constraint.
