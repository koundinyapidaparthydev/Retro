Min Stack

CORE

Definition

A stack that returns the current minimum in O(1). Store pairs (value, minSoFar) or keep a parallel min stack that only pushes when the min changes.

Why it exists

Min stack is the 'augment the data structure' interview.

Approach

  1. Represent each node as {val, min}.
  2. push(x): min = stack empty ?
  3. pop / top: standard stack.
Time O(1) push, pop, top, getMinSpace O(n)

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

second array caches the min after every push

const st = [], mins = [];
function push(x) {
  st.push(x);
  mins.push(mins.length ? Math.min(x, mins[mins.length - 1]) : x);
  console.log("push", x, "min", mins[mins.length - 1]);
}
function pop() {
  st.pop();
  mins.pop();
  console.log("pop  min", mins[mins.length - 1]);
}
push(3); push(1); push(2); pop(); pop();

  • "Walk a tiny example, then code."

You say this first

A stack that returns the current minimum in O(1). Store pairs (value, minSoFar) or keep a parallel min stack that only pushes when the min changes. I'd dry-run a tiny case first, then say the invariant and the complexity (O(1) push, pop, top, getMin time, O(n) space).

Offer the next notch: push(x): min = stack empty ? x : Math.min(x, peek().min); stack.push({val: x, min}).. Tradeoff: You need min of a sliding window — use a monotonic deque, not a min stack. Write the pair version first. Mention the two-stack space trick if they ask.

More notes if you want them

Min stack is the 'augment the data structure' interview. Anyone can get-min in O(n) by scanning. O(1) getMin plus O(1) push/pop is the constraint. The idea — cache the min at each depth — reappears in max-stack, min-queue (need two stacks or a deque), and in 'design a stack with increment on the bottom k.'

Use when: Need current min (or max) of a stack in O(1) with stack semantics.

Skip when: You need min of a sliding window — use a monotonic deque, not a min stack.

Trap: Using < instead of ≤ on the min stack and losing a duplicate min on pop.
