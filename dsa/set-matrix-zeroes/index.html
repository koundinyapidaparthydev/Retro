Set Matrix Zeroes

CORE

Definition

If any cell is 0, its whole row and column become 0. Record the zeros first (sets, or the first row/column as markers) so you do not cascade.

Why it exists

This is the in-place matrix interview about extra memory.

Approach

  1. col0 = false.
  2. for i=1..: for j=1..: if matrix[i][0]==0 || matrix[0][j]==0: matrix[i][j]=0.
  3. Zero the first row if matrix[0][0]==0.
Time O(m n)Space O(1) extra with markers; O(m+n) with arrays

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

mark the zero row and col

const g = [[1, 2, 3], [4, 0, 6], [7, 8, 9]];
const zeroR = new Set(), zeroC = new Set();

for (let r = 0; r < 3; r++) {
  for (let c = 0; c < 3; c++) {
    if (g[r][c] === 0) { zeroR.add(r); zeroC.add(c); }
  }
}
console.log("rows", [...zeroR], "cols", [...zeroC]);

for (let r = 0; r < 3; r++) {
  for (let c = 0; c < 3; c++) {
    if (zeroR.has(r) || zeroC.has(c)) g[r][c] = 0;
  }
}
console.log(g[0]);
console.log(g[1]);
console.log(g[2]);

They ask it like this

  • "Walk a tiny example, then code."

You say this first

If any cell is 0, its whole row and column become 0. Record the zeros first (sets, or the first row/column as markers) so you do not cascade. I'd dry-run a tiny case first, then say the invariant and the complexity (O(m n) time, O(1) extra with markers; O(m+n) with arrays space).

Offer the next notch: for i=1..: for j=1..: if matrix[i][0]==0 || matrix[0][j]==0: matrix[i][j]=0.. Tradeoff: You may use O(m+n) — use two arrays; it is clearer and the same time. State the cascade problem first. Then O(m+n). Then the first-row trick if they want O(1).

More notes if you want them

This is the in-place matrix interview about extra memory. O(mn) copy is trivial. O(m+n) row/col boolean arrays is the clear solution. O(1) extra uses the first row and first column as the marker arrays, plus one flag for the first column (or row) because matrix[0][0] is in both. Interviewers want that flag explained.

Use when: In-place row/col zeroing; similar marker-in-first-row problems.

Skip when: You may use O(m+n) — use two arrays; it is clearer and the same time.

Trap: Zeroing while scanning and creating new zeros.
