Cycle Detection in Directed Graphs

CORE

Definition

A back edge to a gray node (on the current recursion stack) means a directed cycle. Kahn's algorithm: if you cannot peel all nodes, leftover nodes are in cycles.

Why it exists

Course schedule, deadlock, and 'is this graph a DAG?' are this problem.

Approach

  1. color = white.
  2. Kahn: if peeled < n, cycle exists.
Time O(V + E)Space O(V)

Cycle Detection in Directed Graphs

color = white. for each u if white: if dfs(u) return true. dfs: color gray; for v: if gray return true; if white && dfs(v) return true; color black; return false.

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

gray = on the stack, back edge

const g = { A: ["B"], B: ["C"], C: ["A"] };
const color = {};
let cycle = false;

const dfs = (u) => {
  color[u] = 1;
  console.log("enter", u, { ...color });
  for (const v of g[u]) {
    if (color[v] === 1) { cycle = true; console.log("back to gray", v); }
    else if (!color[v]) dfs(v);
  }
  color[u] = 2;
};

dfs("A");
console.log("cycle?", cycle);

You say this first

A back edge to a gray node (on the current recursion stack) means a directed cycle. Kahn's algorithm: if you cannot peel all nodes, leftover nodes are in cycles. I'd dry-run a tiny case first, then say the invariant and the complexity (O(V + E) time, O(V) space).

Offer the next notch: Kahn: if peeled < n, cycle exists.. Tradeoff: Undirected graphs — use the parent version or UF. A directed algorithm on undirected-as-two-arcs treats every edge as a 2-cycle. Course Schedule I is this boolean. II is Kahn's order if peeled === n.

More notes if you want them

Course schedule, deadlock, and 'is this graph a DAG?' are this problem. Visited-alone is not enough: in a directed graph you can see a black node via a cross edge without a cycle. You need the three-color or an explicit recStack. Kahn's leftover is the non-recursive alternative and pairs with topological sort.

Use when: DAG validation, course prerequisites, deadlock detection.

Skip when: Undirected graphs — use the parent version or UF. A directed algorithm on undirected-as-two-arcs treats every edge as a 2-cycle.

Trap: Single boolean visited — misses the gray/black distinction and both false-positives and false-negatives depending on write-up.
