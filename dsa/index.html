Arrays9

Kadane's Algorithm

CORE

Walk the array once. At each number decide: add it to the streak, or start a new streak here.

Prefix Sum

CORE

P[i] = A[0]+…+A[i-1]. Any range sum is P[r]-P[l] in O(1) after O(n) build. The first static range-query structure you should reach for.

Dutch National Flag

CORE

Three-way partition in one pass: low / mid / high pointers. The 0/1/2 sort, and the partition behind 3-way quicksort.

Rotate Array

CORE

Rotate right by k with three reversals: reverse all, reverse the first k, reverse the rest. O(n) time, O(1) extra. Know the extra-array version too.

Set Matrix Zeroes

CORE

If any cell is 0, its whole row and column become 0. Record the zeros first (sets, or the first row/column as markers) so you do not cascade.

Spiral Matrix

CORE

Walk right, down, left, up while shrinking the live rectangle, or simulate direction vectors and turn when the next cell is dead. Generate or read in spiral order.

Difference Array

NEXT

The inverse of prefix sum. To add v on [l,r], do D[l]+=v and D[r+1]-=v. One prefix pass materializes the final array after many range updates.

2-D Prefix Sums

NEXT

P[r][c] = sum of the rectangle from (0,0) to (r,c) exclusive. Any submatrix sum is four corners: bottom-right − left − up + up-left.

Boyer–Moore Majority Vote

NEXT

If a value appears more than n/2 times, a cancel-pairs scan finds it: keep a candidate and a count, decrement on disagreement, switch when count hits 0. Verify in a…

Hashing6

Two Sum and Family

CORE

For each x, ask the map whether target − x was already seen. One pass, O(n). The family includes 3-sum (sort + two pointers), 4-sum, and two-sum on BST/sorted arrays.

Frequency Maps

CORE

Count occurrences in a hashmap (or an array if the alphabet is tiny). The first pass that turns 'is there a duplicate / anagram / majority' into O(n).

Group Anagrams

CORE

Two strings are anagrams if they share a signature. Sort the characters, or count 26 letters, and group words in a map from signature to list.

Prefix Sum plus Hash Map

CORE

A subarray sum equals k iff two prefixes differ by k. Store prefix frequencies (or latest indices) in a map and look up prefix − k as you scan.

Longest Consecutive Sequence

CORE

Put all numbers in a set. Only start a streak from x when x−1 is missing, then walk x+1, x+2, … Each number is touched a constant number of times: O(n).

Design HashMap

NEXT

An array of buckets, a hash to a bucket, and a collision strategy (chaining or open addressing). Grow and rehash when the load factor is high.

Two pointers & sliding window4

Two Pointers

CORE

Put one finger on the left and one on the right, then move them toward each other instead of using two nested loops.

Variable Sliding Window

CORE

Grow a right pointer to include more, shrink a left pointer until the window is valid (or invalid). The two pointers bound the best contiguous segment under a constraint.

Fixed Sliding Window

CORE

Keep a moving box over a stretch of the array. Slide it instead of rebuilding the box from scratch.

Fast and Slow Pointers

CORE

Advance one pointer twice as fast as the other on a linked structure. They meet on a cycle; the slow pointer is at the middle when the fast hits the end.

Binary search9

Binary Search

CORE

If the list is sorted, keep asking “is the middle too small or too big?” and throw away half each time.

Search in Rotated Sorted Array

CORE

One binary search on an array that was sorted then rotated. At every mid, exactly one half is still strictly sorted — search there or discard it.

Linear Search

CORE

Start at the first item and check one by one until you find what you want — or run out of items.

Binary Search on the Answer

NEXT

Binary search the value of the answer itself when feasibility is monotonic: if k works, k+1 also works (or the reverse).

First and Last Occurrence

NEXT

Two binary searches (lower and upper bound) that pin the leftmost and rightmost index of a target in a sorted array with duplicates.

Peak Finding

NEXT

Binary-search a bitonic or unsorted array for an index that is greater than its neighbors. The comparison at mid tells you which side still has a peak.

Exponential Search

ADV

Jump 1, 2, 4, … until you pass the target, then binary search the last doubling window. Ideal for unbounded or infinite sorted streams.

Interpolation Search

ADV

Guess the probe index by assuming values are uniform between lo and hi, like looking up a name in a phone book by its first letter.

Ternary Search

ADV

Trisect a unimodal function and discard a third each time. Use it for finding a min or max on a mountain-shaped real or discrete domain.

Sorting12

Merge Sort

CORE

Split the list in half until pieces are tiny, sort those, then zipper two sorted halves together.

Quick Sort

CORE

Pick a pivot. Put smaller items left, bigger right. Repeat on each side.

Heap Sort

CORE

Build a max-heap in linear time, then repeatedly extract the maximum into the shrinking suffix. Guaranteed n log n, in-place, not stable.

Insertion Sort

CORE

Grow a sorted prefix by inserting A[i] leftward into its place. Fast on small and nearly sorted arrays; the inner loop of production sorts.

Selection Sort

CORE

For each index i, find the minimum of the suffix A[i..] and swap it into place. n swaps, always quadratic comparisons.

Bubble Sort

CORE

Repeatedly swap adjacent out-of-order pairs so the largest remaining element 'bubbles' to the end each pass.

Counting Sort

NEXT

Tally how many times each key in a small integer range appears, then write the output by walking the counts. Linear in n + range.

Radix Sort

NEXT

Stable-sort integers (or fixed-length strings) digit by digit. LSD walks least-significant digit first; MSD walks from the high digit and buckets recursively.

Bucket Sort

NEXT

Scatter elements into buckets by value range, sort each bucket, concatenate. Average linear when keys are uniformly spread.

Randomized Quicksort

NEXT

Choose the pivot uniformly at random (or shuffle first) so the n² worst case is vanishingly unlikely instead of input-dependent.

3-Way Quicksort

NEXT

Dijkstra's Dutch-national-flag partition: split into < pivot, == pivot, > pivot so duplicate keys are finished in one pass.

Cycle Sort

ADV

Write each element directly to its final index by walking cycles of the permutation. Minimizes writes; useful when memory writes are costly.

Stacks & queues10

Valid Parentheses

CORE

Push opening brackets; a closer must match the stack top. The stack is the unmatched prefix. Empty at the end means valid.

Next Greater Element

CORE

Scan left to right while a decreasing stack of indices waits. When the current value is larger, it is the next greater for every popped index.

Monotonic Stack

CORE

Keep the stack strictly increasing or decreasing so the top is the nearest relevant neighbor. One pass computes nearest-greater/smaller for every index.

Min Stack

CORE

A stack that returns the current minimum in O(1). Store pairs (value, minSoFar) or keep a parallel min stack that only pushes when the min changes.

BFS with a Queue, DFS with a Stack

CORE

The same graph walk, different frontier: a queue expands level by level; a stack (or the call stack) dives deep. Know what each visits first.

Largest Rectangle in Histogram

NEXT

For each bar, the largest rectangle with that bar as the shortest uses the nearest shorter bars on left and right as exclusive walls. One monotonic stack finds both.

Sliding Window Maximum

NEXT

The max of every contiguous window of size k, in O(n), using a decreasing deque of candidate indices.

Monotonic Queue

NEXT

A deque kept decreasing (or increasing) so the front is the current window's max (or min). Push at the back with evictions; pop the front when it leaves the window.

Deque (Double-Ended Queue)

NEXT

Push and pop at both ends in O(1). The structure behind monotonic queues, 0-1 BFS, and sliding-window algorithms.

Circular Queue

NEXT

A fixed array with head and tail indices modulo capacity. Enqueue/dequeue O(1) without shifting, used in buffers and BFS pools.

Heaps6

Top-K with a Heap

CORE

A size-k heap of the opposite polarity keeps the k best seen so far in O(n log k). Quickselect is average O(n) if you only need the unordered k.

Heapify and the Heap Property

CORE

A binary heap is an almost-complete binary tree stored in an array. Sift-down from the last parent builds it in O(n); sift-up after an append is O(log n).

Heap Insert and Extract

CORE

push appends and sifts up. pop swaps the root with the last element, shrinks, and sifts down. peek is A[0]. All the priority-queue operations.

Median of a Stream

NEXT

Two heaps: a max-heap of the lower half and a min-heap of the upper half. Rebalance so sizes differ by at most one; the median is one of the roots or their average.

Dijkstra as a Heap Algorithm

NEXT

Dijkstra is BFS with a min-heap of (distance, node) instead of a queue. The heap always expands the closest unsettled node. This topic is the heap view; the graph topic…

Huffman Coding

NEXT

Greedy: repeatedly merge the two rarest symbols into a new parent whose frequency is the sum. A min-heap of trees builds an optimal prefix code.

Linked Lists8

Reverse a Linked List

CORE

Rewire next pointers so a singly linked list runs backward. Iterative three-pointer reverse is the interview default; recursion is the follow-up.

Floyd's Cycle Detection

CORE

Tortoise and hare on a linked list: they meet if and only if a cycle exists; a second same-speed walk from the head finds the entrance.

Merge Two Sorted Lists

CORE

Walk two sorted lists with a dummy tail pointer and always attach the smaller head. The merge step of merge sort, in pointer form.

Nth Node from the End

CORE

Advance a lead pointer n steps, then walk lead and trail together. When lead hits null, trail is n from the end — one pass, ready to delete.

Middle of the List

CORE

One pass with fast and slow pointers: when fast reaches the end, slow is at the middle. No length count, no extra array.

LRU Cache (Pointer Rewiring)

NEXT

A backpack with a max size. Newest thing you used stays on top. When full, the thing you have not touched in the longest time falls out.

Merge K Sorted Lists

NEXT

Merge k sorted linked lists using a min-heap of current heads, or by pairwise / tournament merging. O(N log k) instead of O(Nk).

Intersection of Two Lists

NEXT

Find the first node shared by reference, not by value. Align the tails or use two pointers that swap lists so they meet at the intersection.

Trees & tries12

Trie (Prefix Tree)

CORE

A tree of characters where each root-to-node path is a prefix. Insert, search, and startsWith are O(length), independent of how many words are stored — until the alphabet fans out.

Tree Traversals

CORE

Preorder, inorder, postorder, and level order. Recursive templates plus the explicit-stack and Morris variants you should be able to write.

Lowest Common Ancestor

CORE

The deepest node that has both targets in its subtree. Binary tree: postorder report. BST: walk from the root using key order. Deep trees: binary lifting.

Validate BST

CORE

Every node must lie in (low, high) inherited from ancestors, or inorder must be strictly increasing. Checking only 'left < node < right' is not enough.

Height and Diameter

CORE

Height is the longest root-to-leaf edge count (or node count — agree on the convention). Diameter is the longest path between any two nodes, computable in one DFS.

Path Sum

CORE

Root-to-leaf (or any downward path) whose values add to a target. DFS with a remaining sum, or prefix sums plus a hashmap for 'any path.'

Invert / Flatten a Binary Tree

CORE

Invert swaps left and right at every node (mirror). Flatten rewires the tree into a preorder linked list using right pointers, in place.

Serialize and Deserialize a Tree

NEXT

Encode the shape and values into a string (preorder with null markers, or level order) and parse it back. The markers are what make the reconstruction unique.

Binary Tree Maximum Path Sum

NEXT

A path can bend at a node (left + node + right). A DFS returns the best downward gain to its parent and updates a global best bend.

Kth Smallest in a BST

NEXT

Inorder is sorted, so the k-th visit is the answer. Stop early. With subtree sizes you can walk down in O(h).

Flatten Binary Tree to Linked List

NEXT

Rewrite the tree in place so it becomes a right-linked preorder list. Save the right child, attach the flattened left, then append the old right.

Morris Traversal

ADV

Thread a temporary link from a node's inorder predecessor to itself so you can walk the tree with O(1) extra memory, then unthread.

Graphs22

Breadth-First Search

CORE

Explore a graph like ripples in a pond: everything 1 step away, then 2 steps, then 3. Closest things first.

Depth-First Search

CORE

Go as deep as you can down one path, then back up and try the next branch — like exploring a maze with one hand on the wall.

Dijkstra's Algorithm

CORE

BFS, but edges have different costs. Always expand the cheapest known place next.

Union-Find (Disjoint Set Union)

CORE

Circles of friends. union(a,b) means they become one circle. find(a) tells you which circle a is in.

Topological Sort (Kahn)

CORE

Repeatedly take indegree-0 nodes from a queue. The peel order is a topological order if and only if the graph is a DAG.

Islands and Grid Flood Fill

CORE

Treat the grid as a graph. DFS/BFS/UF from each unvisited land cell paints a whole island. Count the paints. Variants ask perimeters, max area, or surrounded regions.

Connected Components

CORE

In an undirected graph, a component is a maximal reachable set. DFS/BFS floods one; Union-Find merges them from the edge list. Count the floods or the leftover roots.

BFS Shortest Path

CORE

On unweighted edges, BFS distance is the shortest hop count. Store parents if you must reconstruct one such path.

Cycle Detection in Directed Graphs

CORE

A back edge to a gray node (on the current recursion stack) means a directed cycle. Kahn's algorithm: if you cannot peel all nodes, leftover nodes are in cycles.

Cycle Detection in Undirected Graphs

CORE

DFS: a visited neighbor that is not your parent is a cycle. Union-Find: if two ends of an edge are already in the same component, that edge closes a cycle.

Bipartite Check

CORE

Two-color the graph with BFS or DFS. A neighbor the same color as you is an odd cycle — not bipartite.

Topological Sort (DFS)

NEXT

Run DFS and append each node after its descendants finish. Reverse the finish list (or push onto a stack) to get a topo order.

Bellman-Ford

NEXT

Relax every edge V−1 times. Handles negative weights and reports a negative cycle if the V-th pass still improves a reachable distance.

Kruskal's MST

NEXT

Sort edges by weight, add an edge when it joins two components (Union-Find). The first V−1 accepted edges are a minimum spanning tree.

Prim's MST

NEXT

Grow a tree from a start node, always adding the cheapest edge that leaves the tree. A min-heap of candidate edges (or nodes) implements the pick.

Floyd-Warshall

NEXT

Triple loop: try each intermediate k, then i, j. dp[i][j] = min(dp[i][j], dp[i][k]+dp[k][j]). All-pairs shortest paths including negatives (no negative cycles).

0-1 BFS

ADV

Edges have only weights 0 or 1. Use a deque: push_front on a 0-relax, push_back on a 1-relax. Distances come out like Dijkstra but in O(V+E).

A* Search

ADV

Dijkstra with a heuristic: expand the node with the smallest f = g + h, where g is distance from start and h estimates distance to the goal. Admissible h never…

Bridges and Articulation Points

ADV

Tarjan's DFS times: a tree edge u–v is a bridge if no back edge from v's subtree climbs to u or above. Articulation points have a similar low-link test (plus a special…

Euler Path and Circuit (Hierholzer)

ADV

A trail that uses every edge once. Hierholzer: DFS-consume edges and append nodes on exit (postorder). Reverse the list for the path. Check degree conditions first.

Strongly Connected Components (Kosaraju)

ADV

DFS to compute finish order, reverse every edge, DFS again in decreasing finish time. Each tree in the second forest is an SCC.

Tarjan's SCC

ADV

One DFS: push nodes on a stack, track low-links. When low[u] === tin[u], u is the root of an SCC — pop the stack until u.

Recursion & backtracking10

Subsets (Power Set)

CORE

At each element, choose include or exclude. The binary tree of decisions enumerates all 2^n subsets; handle duplicates by skipping equal neighbors.

Permutations

CORE

Build a permutation by trying each unused element at the next position. Swap-in-place or a used[] boolean; skip equal candidates for unique perms.

Combinations

CORE

Choose k items from n without regard to order. Recurse with a start index so each combination is built in nondecreasing index order.

Generate Parentheses

CORE

Build a string of n pairs by adding '(' if you still have opens left and ')' if closes would not exceed opens. Catalan-many valid strings, no invalid ones generated.

Word Search

CORE

DFS from each cell, walking four directions to match the next character, marking the path so you do not reuse a cell. Backtrack the mark.

Recursion and Memoization

CORE

Express a problem as smaller self-similar cases, cache answers by state so overlapping subproblems are solved once. The bridge from brute-force DFS to DP.

Divide and Conquer

CORE

Split the instance, solve parts independently, combine. The Master Theorem turns T(n) = a T(n/b) + f(n) into the closed form you quote in interviews.

N-Queens

NEXT

Place n queens so none share a row, column, or diagonal. Backtrack row by row, pruning with column and diagonal occupancy sets.

Sudoku Solver

NEXT

Fill empty cells by trying digits 1–9 that are legal in the row, column, and 3×3 box, then backtrack. Constraint checks decide whether the search lives.

Closest Pair of Points

ADV

Divide the plane by x-median, recurse, then scan a strip of width δ around the midline. The strip has a 7-neighbor property that keeps the combine linearithmic.

Dynamic Programming18

0/1 Knapsack

CORE

A backpack that can take each item at most once. For every item you ask: take it, or skip it, and remember the best leftover capacity.

Coin Change

CORE

Minimum coins (or number of combinations) to make amount. Unbounded knapsack with a careful base and an impossible sentinel.

Longest Common Subsequence

CORE

dp[i][j] = dp[i-1][j-1]+1 if A[i-1]==B[j-1], else max(dp[i-1][j], dp[i][j-1]). The 2-D string DP template.

Longest Increasing Subsequence

CORE

O(n²) DP: dp[i] = 1 + max dp[j] over j<i and A[j]<A[i]. O(n log n): maintain a tails array and binary-search the insertion point.

Edit Distance (Levenshtein)

CORE

dp[i][j] is the min inserts/deletes/replaces to turn A[:i] into B[:j]. A match copies the diagonal; otherwise 1+min(insert, delete, replace).

Climbing Stairs

CORE

Ways to reach step n with 1- and 2-steps is Fibonacci. Generalize to 1..k steps with a sliding window sum.

House Robber

CORE

Max sum of a subsequence with no two adjacent. dp[i] = max(dp[i-1], dp[i-2] + A[i]). Circle and tree variants change the graph, not the idea.

Fibonacci-Style DP

CORE

dp[i] depends on a constant number of previous answers. The teaching family: Fib, climbing stairs, and every 'number of ways to reach i' recurrence.

Grid DP

CORE

dp[r][c] from the top/left (or other incoming directions). Unique paths, min path sum, dungeon game, and falling path are one family.

Unbounded Knapsack

NEXT

Each item type can be taken any number of times. The 1-D capacity loop runs forward so a newly taken item can be reused in the same pass.

Decode Ways

NEXT

A digit string maps to letters as 1–26. dp[i] adds the one-digit and two-digit decodes that form valid codes ending at i. Zeros are the trap.

Palindrome DP

NEXT

isPal[i][j] is true if s[i]==s[j] and the inside is a palindrome. Expand-around-center is often simpler; DP shines for palindrome partitions and LPS.

Interval DP

NEXT

dp[l][r] depends on smaller intervals. Enumerate length, then l, then a split. Matrix chain, burst balloons, palindrome cuts, and stone games share this loop nest.

Matrix Chain Multiplication

ADV

Interval DP: dp[i][j] is the min cost to multiply matrices i..j. Try every split k and add the cost of the final multiply.

Burst Balloons

ADV

Think of the last balloon you burst in an open interval. dp[l][r] = max over k in (l,r) of nums[l]*nums[k]*nums[r] + dp[l][k] + dp[k][r].

Bitmask DP

ADV

When n ≤ 20, a subset is an integer mask. dp[mask] (and maybe a location) iterates over bits to add one element. TSP, assignment, and 'smallest sufficient team' live here.

Tree DP

ADV

Postorder: a node's answer from its children's answers. House Robber III, diameter, and rerooting (compute for every root in two DFS) are the templates.

Digit DP

ADV

Count numbers ≤ N whose digits satisfy a property. DFS on (position, tight, leftover-state) with memo. Tight says you are still prefix-matching N.

Greedy8

Interval Scheduling

CORE

To pick the maximum number of non-overlapping intervals, always take the one that finishes first among those that start after the last you accepted.

Jump Game

CORE

Track the farthest index reachable so far. You can reach i only if i ≤ farthest; then extend farthest by i + A[i]. Jump Game II counts greedy windows of a BFS layer.

Meeting Rooms

CORE

Can one person attend all? Sort by start and check adjacent ends. How many rooms? Sweep start/end events or a min-heap of end times — the max depth of the sweep is the answer.

Gas Station

CORE

If total gas ≥ total cost, a circuit exists. The unique start (when unique) is the index after the worst prefix deficit. One pass, O(1) extra.

Fractional Knapsack

CORE

Take items in decreasing value/weight ratio; the last item may be split. Greedy is optimal here and illegal in 0/1 knapsack.

Assign Cookies

CORE

Sort children by greed and cookies by size. Walk two pointers: give the smallest cookie that satisfies the next child. That maximizes the number of content children.

Candy Distribution

NEXT

Give children candies so neighbors with a higher rating get more. Two passes (up the slopes, then down) or a one-array peak-and-valley fill. Greedy local slopes are enough.

Kruskal and Prim as Greedy

NEXT

Both MST algorithms are the cut property in action: the cheapest edge across a cut is safe. Kruskal picks globally cheapest safe edges; Prim grows one tree by the…

Strings9

KMP (Knuth–Morris–Pratt)

CORE

Build the longest proper prefix-suffix table (lps/pi) of the pattern, then match in one pass without rewinding the text. O(n+m) string search.

Sliding Window on Strings

CORE

Variable or fixed windows with a char-count debt. Minimum window substring, longest without repeats, and find-all-anagrams are the same two-pointer plus a map.

Trie-Based Search

CORE

Walk a trie to answer prefix queries, autocomplete, and grid word search. The tree turns a dictionary into a state machine of prefixes.

Rabin–Karp

NEXT

Rolling hash the pattern and every text window of the same length. Equal hashes are candidate matches you verify. Average linear, worst-case quadratic if you skip…

Z-Algorithm

NEXT

Z[i] is the longest substring starting at i that matches the prefix of the string. A linear scan with a maintained [L,R] match window computes the whole Z-box.

Manacher's Algorithm

ADV

Longest palindromic substring in O(n). Mirror radii inside a current palindrome window, then expand only when the mirror does not pin the answer.

Suffix Array

ADV

The sorted list of all suffixes of s, usually stored as starting indices. With LCP (Kasai), you get longest repeated substring and many comparison queries in log time…

Suffix Tree

ADV

A compressed trie of all suffixes. Ukkonen's algorithm builds it in O(n). Powerful, rarely coded in interviews; know what queries it answers in O(|P|).

Aho–Corasick

ADV

A trie of all patterns plus failure links (KMP on the trie). One scan of the text reports every occurrence of every pattern in O(n + hits + build).

Bits5

XOR Tricks

CORE

XOR is associative, commutative, and its own inverse. x^x=0, x^0=x. That is why XOR of a range finds the unique single number and why you can swap without a temp.

Counting Set Bits

CORE

Kernighan clears one set bit per loop. Hardware popcount is O(1). The DP counting-bits problem uses dp[i] = dp[i>>1] + (i&1).

Set, Unset, and Toggle Bits

CORE

OR with a shifted 1 to set, AND with its complement to clear, XOR to flip. Masks are how you treat an integer as a small set or a packed flag word.

Bitmask Subsets

NEXT

Enumerate all 2^n subsets as integers 0..(1<<n)-1. Iterate set bits, walk submasks, and build next-masks. The implementation layer under bitmask DP.

Brian Kernighan's Trick

NEXT

n & (n-1) drops the lowest set bit. n & -n isolates it. Together they iterate, count, and test powers of two without scanning all 32 bits.

Math7

Euclid GCD and LCM

CORE

gcd(a,b) = gcd(b, a mod b), then 0. lcm(a,b) = a / gcd * b to avoid overflow. The extended algorithm also finds Bézout coefficients for modular inverses.

Sieve of Eratosthenes

CORE

Mark multiples of each prime p starting at p². After one pass, unmarked numbers are prime. Linear and segmented sieves exist when N is large.

Fast Exponentiation

CORE

Compute a^e (mod m) by squaring: square the base, multiply into the answer on odd bits of e. O(log e) multiplications, not e.

Modular Arithmetic

CORE

Work in Z/mZ: add and multiply then reduce. Division is multiply by the modular inverse, which exists iff gcd(a,m)=1. Watch negative residues and overflow.

Integer Factorization

NEXT

Trial divide to sqrt(n) for a single n. After an SPF sieve, factor many n in O(log n). Pollard's Rho for 64-bit contest numbers. Unique factorization is why gcd works.

nCr and Modular Inverse

NEXT

nCr = n! / (r! (n-r)!). Mod a prime, divide by multiplying inv factorials. Precompute fact[i] and invFact[i] in O(N + log MOD).

Catalan Numbers

NEXT

C_0=1, C_{n+1} = Σ C_i C_{n-i}, and C_n = (1/(n+1)) * (2n choose n). They count valid parentheses, BSTs, monotonic paths, and triangulations.

Advanced structures6

Segment Tree

ADV

A binary tree over array ranges. Each node stores an aggregate of [l,r]. Point update and range query are O(log n) by walking O(1) nodes per level.

Fenwick Tree (Binary Indexed Tree)

ADV

An array where index i stores a prefix chunk of length i&-i. Prefix sums and point adds in O(log n) with two tiny loops. Less general than a segment tree, much less code.

Sparse Table

ADV

st[k][i] = combine of 2^k elements starting at i. Idempotent range queries (min, max, gcd) become O(1) after O(n log n) build. No updates.

Lazy Propagation

ADV

Defer a range update on a segment-tree node by storing it in a lazy tag. Push the tag to children only when you must go down. Range update and range query stay O(log n).

Ordered Set / Policy-Based Tree

ADV

A balanced BST that also supports order-statistic queries: find-by-rank and rank-of-key in O(log n). C++ pbds, Java TreeSet plus Fenwick, or a size-augmented treap/splay.

Persistent Segment Tree

ADV

Each update allocates O(log n) new nodes along the path and reuses the rest. You keep a root per version and query any historical snapshot in O(log n).
