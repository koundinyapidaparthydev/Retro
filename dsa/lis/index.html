Longest Increasing Subsequence

CORE
GoogleoftenMetasometimesPatience / n log n follow-up.

The problem they give you

They will not say “Longest Increasing Subsequence.” They describe this:

Given: A sequence. You may drop numbers but you must keep the leftover in the same order. They need not sit next to each other.

Find: Length of the longest leftover that strictly rises.

Tiny example: [10, 9, 2, 5, 3, 7, 101, 18] → 2,5,7,101 (or 2,3,7,18). Length 4.

Name of the tool

O(n²) DP: dp[i] = 1 + max dp[j] over j<i and A[j]<A[i]. O(n log n): maintain a tails array and binary-search the insertion point.

Why this tool

LIS is the sequence DP everyone meets.

Approach

  1. n²: dp[i]=1; for j<i if A[j]<A[i] dp[i]=max(dp[i], dp[j]+1).
  2. n log n: tails=[].

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

tails: smallest end of each length

const nums = [10, 9, 2, 5, 3, 7];
const tails = [];

for (const x of nums) {
  let lo = 0, hi = tails.length;
  while (lo < hi) {
    const mid = (lo + hi) >> 1;
    if (tails[mid] < x) lo = mid + 1;
    else hi = mid;
  }
  tails[lo] = x;
  console.log("place", x, "→", [...tails]);
}
console.log("LIS length", tails.length);

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Length only.
  • Print one such leftover.

You say this first

O(n²) DP: dp[i] = 1 + max dp[j] over j<i and A[j]<A[i]. O(n log n): maintain a tails array and binary-search the insertion point. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n²) or O(n log n) time, O(n) space).

Offer the next notch: n log n: tails=[]. for x of A: i = lower_bound(tails, x); if i===tails.length tails.push(x); else tails[i]=x. return tails.length.. Tradeoff: Contiguous — that is Kadane-like or two pointers, not LIS. Write n² first unless they demand n log n. Say tails is not the sequence.

More notes if you want them

LIS is the sequence DP everyone meets. The n² version is the one you must be able to write and reconstruct. The n log n patience-sorting / tails array is the follow-up and a binary-search-on-answer cousin. Russian-doll envelopes is LIS after a clever sort. Interviewers also ask LDS and 'number of LIS.'

Use when: Longest increasing / decreasing / bitonic subsequence; envelope / box stacking after sort.

Skip when: Contiguous — that is Kadane-like or two pointers, not LIS.

Trap: Using ≤ vs < (non-decreasing vs increasing).
