Islands and Grid Flood Fill

CORE
MetahotAmazonhotGoogleoftenGrid BFS/DFS — Meta and Amazon staple.

The problem they give you

They will not say “Islands and Grid Flood Fill.” They describe this:

Given: A grid of land and water. Land touches land up/down/left/right.

Find: How many islands? An island is one blob of connected land.

Tiny example: Two land cells sharing a side → 1 island. Two lands on a diagonal only → 2 islands.

Name of the tool

Treat the grid as a graph. DFS/BFS/UF from each unvisited land cell paints a whole island. Count the paints. Variants ask perimeters, max area, or surrounded regions.

Why this tool

Number of Islands is the grid-graph interview.

Approach

  1. ans=0.
  2. dfs: bounds + land check, mark, recurse 4 dirs.
  3. For max area, return 1+sum of recursive calls instead of only marking.

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

flood-fill 1s to 0

const grid = [
  [1, 1, 0],
  [1, 0, 0],
  [0, 0, 1],
];

const flood = (r, c) => {
  if (r < 0 || c < 0 || r > 2 || c > 2 || !grid[r][c]) return;
  grid[r][c] = 0;
  for (const [dr, dc] of [[1, 0], [-1, 0], [0, 1], [0, -1]]) flood(r + dr, c + dc);
};

let count = 0;
for (let r = 0; r < 3; r++) {
  for (let c = 0; c < 3; c++) {
    if (!grid[r][c]) continue;
    count++;
    flood(r, c);
    console.log("island", count, "seed", [r, c]);
  }
}
console.log("count", count);

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Count islands.
  • Area of the largest island.
  • Flip land that does not touch the border (surrounded regions).

You say this first

Treat the grid as a graph. DFS/BFS/UF from each unvisited land cell paints a whole island. Count the paints. Variants ask perimeters, max area, or surrounded regions. I'd dry-run a tiny case first, then say the invariant and the complexity (O(rows · cols) time, O(rows · cols) worst-case stack; UF is O(rc) space).

Offer the next notch: dfs: bounds + land check, mark, recurse 4 dirs.. Tradeoff: You need shortest path on the grid — BFS, not a component count. Ask 4- vs 8-connected. Write a dirs array. Do not copy-paste four ifs if you can loop.

More notes if you want them

Number of Islands is the grid-graph interview. If you can flood a component, you can do max-area, Pacific-Atlantic, surrounded regions, and distinct islands (normalize shapes). Interviewers care about bounds checks, marking visited (often in-place as '0'), and not double-counting.

Use when: Any grid component problem: islands, regions, lakes, rain flow.

Skip when: You need shortest path on the grid — BFS, not a component count.

Trap: Recursing into water or out of bounds.
