The problem they give you

They will not say “Palindrome DP.” They describe this:

Given: A string. A palindrome reads the same forward and back.

Find: Longest palindrome that is a contiguous slice — or, if they say so, a leftover that may skip letters. Or min cuts so every piece is a palindrome.

Tiny example: babad → bab or aba, length 3. cbbd → bb. subsequence on bbbab → bbbb.

Name of the tool

isPal[i][j] is true if s[i]==s[j] and the inside is a palindrome. Expand-around-center is often simpler; DP shines for palindrome partitions and LPS.

Why this tool

Longest palindromic substring, palindrome partitioning, and longest palindromic subsequence (LCS of s and reverse(s)) are a cluster.

Approach

  1. Build is[i][j] by increasing j-i.
  2. Or expand(l,r) while in bounds and equal, update best.
  3. For LPS subsequence, fill the interval table by length.

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Longest palindromic slice.
  • Longest palindromic leftover (skips allowed).
  • Min cuts so every piece is a palindrome.

You say this first

isPal[i][j] is true if s[i]==s[j] and the inside is a palindrome. Expand-around-center is often simpler; DP shines for palindrome partitions and LPS. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n²) typical; O(n) Manacher for longest substring time, O(n²) table or O(1) expand space).

Offer the next notch: Or expand(l,r) while in bounds and equal, update best.. Tradeoff: You only need to check one string — two pointers from the ends. Ask substring vs subsequence first. Those are different problems.

More notes if you want them

Longest palindromic substring, palindrome partitioning, and longest palindromic subsequence (LCS of s and reverse(s)) are a cluster. Interviewers accept expand-around-center for LPS substring (O(n²) time, O(1) space). They want interval DP for min cuts. Manacher is the O(n) flex, not required unless they ask.

Use when: Palindromic substring / subsequence / partition problems.

Skip when: You only need to check one string — two pointers from the ends.

Trap: Forgetting even-length centers.
