Floyd's Cycle Detection

CORE

Definition

Tortoise and hare on a linked list: they meet if and only if a cycle exists; a second same-speed walk from the head finds the entrance.

Why it exists

Floyd's algorithm is the O(1)-space cycle answer.

Approach

  1. slow = fast = head.
  2. ptr = head.
  3. Return ptr as the entrance.
Time O(n)Space O(1)

Floyd's Cycle Detection

slow = fast = head. Loop: if fast or fast.next is null, return no cycle. slow = slow.next; fast = fast.next.next. If slow === fast, break.

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

fast gains one per step; reset to find the entrance

const n = (val) => ({ val, next: null });
const a = n(1), b = n(2), c = n(3), d = n(4);
a.next = b; b.next = c; c.next = d; d.next = b; // cycle at 2
let slow = a, fast = a;
do {
  slow = slow.next;
  fast = fast.next.next;
  console.log("step", slow.val, fast.val);
} while (slow !== fast);
let p = a;
while (p !== slow) {
  p = p.next;
  slow = slow.next;
}
console.log("entrance", p.val);

They ask it like this

  • "Here's an array / graph / string. Can you use Floyd's Cycle Detection?"
  • "State both phases. If they only asked 'has a cycle,' still mention you know how to find the entrance."
  • "Walk a tiny example, then code."

You say this first

Tortoise and hare on a linked list: they meet if and only if a cycle exists; a second same-speed walk from the head finds the entrance. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n) time, O(1) space).

Offer the next notch: ptr = head. While ptr !== slow: ptr = ptr.next; slow = slow.next.. Tradeoff: You already have a visited set and O(n) space is allowed and simpler for the audience. State both phases. If they only asked 'has a cycle,' still mention you know how to find the entrance.

More notes if you want them

Floyd's algorithm is the O(1)-space cycle answer. The visited-set solution is correct and you should mention it, then say you can do better. Interviewers use Linked List Cycle II (return the entrance node) as the real test: detection is not enough. The same math appears in 'find the duplicate number' when the array is treated as a functional graph.

Use when: Detect or locate a cycle in a singly linked list.

Skip when: You already have a visited set and O(n) space is allowed and simpler for the audience.

Trap: Starting the entrance phase from the meet without resetting one pointer to the head.
