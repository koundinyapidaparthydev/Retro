Recursion and Memoization

CORE

Definition

Express a problem as smaller self-similar cases, cache answers by state so overlapping subproblems are solved once. The bridge from brute-force DFS to DP.

Why it exists

Almost every backtracking and DP interview starts as a recursive function.

Approach

  1. Write the recursive function with clear parameters and a base case.
  2. Identify the state tuple.
  3. At the top of the function: if the state is cached, return it.

cache fib so overlapping calls skip work

const memo = new Map([[0, 0], [1, 1]]);

function fib(n) {
  if (memo.has(n)) return memo.get(n);
  console.log("miss", n);
  const v = fib(n - 1) + fib(n - 2);
  memo.set(n, v);
  return v;
}

console.log("fib(6)", fib(6));
console.log("cached keys", [...memo.keys()]);

You say this first

Express a problem as smaller self-similar cases, cache answers by state so overlapping subproblems are solved once. The bridge from brute-force DFS to DP. I'd dry-run a tiny case first, then say the invariant and the complexity (O(|states| × work per state) once memoized time, O(|states|) plus O(depth) stack space).

Offer the next notch: Identify the state tuple. Create a map or array keyed by that tuple, initialized as 'unknown.'. Tradeoff: No overlap (N-Queens, unique permutations) — memo does not help the exponential tree. Narrate: 'brute recursion, then I'll cache on (i, remaining).' More notes if you want them

Almost every backtracking and DP interview starts as a recursive function. If you cannot write the raw recursion — arguments, base cases, what you return — you cannot memoize it or convert it to a table. Interviewers want to hear the two questions: does it have overlapping subproblems, and what is the state that uniquely identifies a subproblem? Memoization is DP with the call stack as the evaluation order.

Use when: Optimal substructure plus overlapping subproblems: fib, knapsack, grid paths, digit DP.

Skip when: No overlap (N-Queens, unique permutations) — memo does not help the exponential tree.

Trap: Caching a state that omits a parameter (e.g. forgetting 'last picked index' in LIS-style DFS).
