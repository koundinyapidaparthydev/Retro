Fenwick Tree (Binary Indexed Tree)

ADV

The problem they give you

They will not say “Fenwick Tree (Binary Indexed Tree).” They describe this:

Given: An array. Point adds and prefix or range sums.

Find: Add to one index and read a prefix fast. Range [l, r] is prefix(r) − prefix(l−1).

Tiny example: [1, 2, 3, 4], add +5 at index 2 → [1, 7, 3, 4]; sum of [2, 4] = 14.

Name of the tool

An array where index i stores a prefix chunk of length i&-i. Prefix sums and point adds in O(log n) with two tiny loops. Less general than a segment tree, much less code.

Why this tool

Fenwick is the structure you actually type in a timed interview for range-sum + point-update.

Approach

  1. bit = zeros(n+1).
  2. add(i,v) and sumPrefix(i) as above (i is 1-based).
  3. Build: for i,x of A: add(i+1, x), or the linear build by pushing to i+=i&-i once per i.

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

i += i & -i climbs; i -= i & -i sums

const n = 5;
const bit = Array(n + 1).fill(0);

function add(i, v) {
  for (; i <= n; i += i & -i) bit[i] += v;
}

function prefix(i) {
  let s = 0;
  for (; i > 0; i -= i & -i) s += bit[i];
  return s;
}

add(1, 2);
add(2, 3);
add(4, 5);
console.log("bit", bit.slice(1));
console.log("sum 1..2", prefix(2));
console.log("sum 1..4", prefix(4));
console.log("range 3..4", prefix(4) - prefix(2));

You say this first

An array where index i stores a prefix chunk of length i&-i. Prefix sums and point adds in O(log n) with two tiny loops. Less general than a segment tree, much less code. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n) build, O(log n) add/prefix time, O(n) space).

Offer the next notch: add(i,v) and sumPrefix(i) as above (i is 1-based).. Tradeoff: Range min/gcd — segment tree. Write the two loops from memory. Mention 1-based.

More notes if you want them

Fenwick is the structure you actually type in a timed interview for range-sum + point-update. The i & -i jump is Kernighan's lowest-set-bit. Range add + point query is a Fenwick on a difference array. 2-D Fenwick appears in 'range sum query 2D mutable.' If you can write add and sumPrefix in six lines, you look fluent.

Use when: Prefix / range sums with point updates; frequency tables on compressed coordinates; inversion counts.

Skip when: Range min/gcd — segment tree.

Trap: 0-based i and i&-i never moving (infinite loop on 0).
