KMP (Knuth–Morris–Pratt)

CORE

The problem they give you

They will not say “KMP (Knuth–Morris–Pratt).” They describe this:

Given: A long text and a shorter pattern.

Find: Every index where the pattern starts. After a mismatch, do not rewind the text.

Tiny example: "ababcabc" / "abc" → starts at 2 and 5.

Name of the tool

Build the longest proper prefix-suffix table (lps/pi) of the pattern, then match in one pass without rewinding the text. O(n+m) string search.

Why this tool

KMP is the linear-time pattern search you should be able to explain and code.

Approach

  1. Build lps of the pattern (length m).
  2. i=0 (text), j=0 (pattern).
  3. Else if j>0, j=lps[j-1]; else i++.

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Find the first or every occurrence of a pattern.
  • Is the string a repeat of one substring?
  • Fewest characters to add in front to make a palindrome.

You say this first

Build the longest proper prefix-suffix table (lps/pi) of the pattern, then match in one pass without rewinding the text. O(n+m) string search. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n + m) time, O(m) space).

Offer the next notch: i=0 (text), j=0 (pattern). while i<n: if text[i]==pat[j], i++, j++, and if j==m record a hit and j=lps[j-1].. Tradeoff: Many patterns — Aho–Corasick. Define lps[i] in words, then write the builder, then the search. Do not start in the middle.

More notes if you want them

KMP is the linear-time pattern search you should be able to explain and code. Naive search is O(nm). Interviewers use 'implement strStr' and 'shortest palindrome' / 'repeated substring pattern' as LPS applications. If you only remember 'the pi array,' they will ask what pi[i] means when a mismatch happens — that sentence is the algorithm.

Use when: Single pattern search in a long text; LPS-based string properties.

Skip when: Many patterns — Aho–Corasick.

Trap: Rewinding i on mismatch (that is naive, or a buggy KMP).
