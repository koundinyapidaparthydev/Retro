Dijkstra's Algorithm

CORE
GoogleoftenUberhotMetasometimesWeighted shortest path, maps.

Definition

BFS, but edges have different costs. Always expand the cheapest known place next.

Why it exists

Dijkstra is the weighted-graph interview.

Approach

  1. dist = ∞, dist[s] = 0.
  2. Pop [d,u]; continue if d > dist[u].
  3. Return dist[t] or the parent path.
Time O((V + E) log V) binary heap; O(V²) arraySpace O(V + E)

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

settle the nearest unsettled node

const g = {
  A: [["B", 4], ["C", 1]],
  B: [["D", 1]],
  C: [["B", 2], ["D", 5]],
  D: [],
};
const dist = { A: 0, B: Infinity, C: Infinity, D: Infinity };
const seen = new Set();

while (seen.size < 4) {
  const u = Object.keys(dist).filter((k) => !seen.has(k))
    .sort((a, b) => dist[a] - dist[b])[0];
  seen.add(u);
  console.log("settle", u, dist[u]);
  for (const [v, w] of g[u]) {
    if (dist[u] + w < dist[v]) dist[v] = dist[u] + w;
  }
}

You say this first

Greedy shortest paths for non-negative weights: always expand the node with the smallest tentative distance, then relax its edges. I'd dry-run a tiny case first, then say the invariant and the complexity (O((V + E) log V) binary heap; O(V²) array time, O(V + E) space).

Offer the next notch: Pop [d,u]; continue if d > dist[u]. For each (v,w): nd = d+w; if nd < dist[v]: dist[v]=nd; push [nd,v]; parent[v]=u.. Tradeoff: Negative edges — Bellman-Ford. Unweighted — BFS. 0-1 weights — 0-1 BFS. Write the stale-skip. Talk through a 3-node negative-weight counterexample if they ask why not negatives.

More notes if you want them

Dijkstra is the weighted-graph interview. Network delay time, cheapest flights with constraints (sometimes not Dijkstra), path with minimum effort, and map routing all sit here. You must state the non-negative assumption, implement a min-heap of pairs, and skip stale heap entries. If you cannot write the loop, you do not know it.

Use when: Non-negative edge weights, single source (or small number of sources).

Skip when: Negative edges — Bellman-Ford. Unweighted — BFS. 0-1 weights — 0-1 BFS.

Trap: Using a queue (BFS) on weighted edges.
