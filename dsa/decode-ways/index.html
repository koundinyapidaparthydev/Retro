Decode Ways

NEXT

Definition

A digit string maps to letters as 1–26. dp[i] adds the one-digit and two-digit decodes that form valid codes ending at i. Zeros are the trap.

Why it exists

Decode Ways looks like stairs and dies on '10', '06', and '230'.

Approach

  1. dp[0]=1.
  2. Return dp[n].
Time O(n)Space O(1) rolling

dp[0]=1. for… · Return…

dp[0]=1. for i=1..n: ways=0; if one-digit valid, ways += dp[i-1]; if i>=2 and two-digit valid, ways += dp[i-2]; dp[i]=ways.

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

one digit or a valid pair

const s = "226";
const dp = Array(s.length + 1).fill(0);
dp[0] = 1;

for (let i = 1; i <= s.length; i++) {
  if (s[i - 1] !== "0") dp[i] += dp[i - 1];
  if (i >= 2) {
    const two = Number(s.slice(i - 2, i));
    if (two >= 10 && two <= 26) dp[i] += dp[i - 2];
  }
  console.log("prefix", s.slice(0, i), "ways", dp[i]);
}

You say this first

A digit string maps to letters as 1–26. dp[i] adds the one-digit and two-digit decodes that form valid codes ending at i. Zeros are the trap. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n) time, O(1) rolling space).

Offer the next notch: Return dp[n]. If you ever get stuck with 0 ways mid-string, later stays 0.. Tradeoff: You need the actual decodings listed — backtrack, and only if n is tiny. Walk '10', '12', '27', '06', '0' before coding. Those five decide your conditions.

More notes if you want them

Decode Ways looks like stairs and dies on '10', '06', and '230'. Interviewers use it to see whether your recurrence checks validity, not just length. The follow-up with '*' (Decode Ways II) is a careful case-bash on the same DP.

Use when: Parse a string under local coding rules; number of interpretations.

Skip when: You need the actual decodings listed — backtrack, and only if n is tiny.

Trap: Treating 0 as a valid one-digit code.
