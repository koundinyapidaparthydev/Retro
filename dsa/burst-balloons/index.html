Burst Balloons

ADV

The problem they give you

They will not say “Burst Balloons.” They describe this:

Given: Balloons in a row, each with a number. Burst one: you score left × this × right (missing ends count as 1).

Find: Maximum score if you burst them all. Think of the last balloon you burst between two walls, not the first.

Tiny example: [3, 1, 5, 8]. One optimal order scores 167.

Name of the tool

Think of the last balloon you burst in an open interval. dp[l][r] = max over k in (l,r) of nums[l]*nums[k]*nums[r] + dp[l][k] + dp[k][r].

Approach

  1. vals = [1, ...nums, 1].
  2. for len=2..n-1: for l=0; l+len<n; l++: r=l+len; for k=l+1..r-1: dp[l][r] = max(dp[l][r], vals[l]*vals[k]*vals[r] + dp[l][k] + dp[k][r]).
  3. Return dp[0][n-1].

You say this first

Think of the last balloon you burst in an open interval. dp[l][r] = max over k in (l,r) of nums[l]*nums[k]*nums[r] + dp[l][k] + dp[k][r]. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n³) time, O(n²) space).

Offer the next notch: for len=2..n-1: for l=0; l+len<n; l++: r=l+len; for k=l+1..r-1: dp[l][r] = max(dp[l][r], vals[l]*vals[k]*vals[r] + dp[l][k] + dp[k][r]).. Tradeoff: You burst in a fixed order — then it is a simulation, not this DP. Say 'k is the last balloon between the walls' before the loops.

More notes if you want them

This is the interval-DP interview that feels backwards until you recast 'last burst' instead of 'first burst.' First-burst thinking creates dependencies on a changing array. Last-burst thinking makes subintervals independent. That reframe is the lesson.

Use when: Last-event interval games: burst balloons, burst extra, some stone games.

Skip when: You burst in a fixed order — then it is a simulation, not this DP.

Trap: First-burst recurrence that needs the current neighbors — you will want a bitmask (n≤12) instead of interval DP, which is a different (worse) state.
