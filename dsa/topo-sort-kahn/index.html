Topological Sort (Kahn)

CORE

The problem they give you

They will not say “Topological Sort (Kahn).” They describe this:

Given: Jobs with prerequisites. A job is ready only when every arrow into it is done.

Find: An order to run every job. If some jobs never become ready, say it is impossible.

Tiny example: A before C, B before C. Orders A,B,C and B,A,C both work. A←C←A is impossible.

Name of the tool

Repeatedly take indegree-0 nodes from a queue. The peel order is a topological order if and only if the graph is a DAG.

Why this tool

Kahn's algorithm is the interview-friendly topo sort: BFS-shaped, easy to detect cycles, easy to produce the lexicographically smallest order with a m…

Approach

  1. Compute indegree[].
  2. While queue: u = pop; order.push(u); for v in adj[u]: indegree[v]--; if 0, push v.
  3. If order.length < n, return error (cycle).

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

queue the indegree-0 nodes

const g = { A: ["C"], B: ["C"], C: ["D"], D: [] };
const indeg = { A: 0, B: 0, C: 0, D: 0 };
for (const u of Object.keys(g)) for (const v of g[u]) indeg[v]++;

const q = Object.keys(indeg).filter((u) => indeg[u] === 0);
const order = [];

while (q.length) {
  const u = q.shift();
  order.push(u);
  console.log("take", u, "left", { ...indeg });
  for (const v of g[u]) if (--indeg[v] === 0) q.push(v);
}
console.log("order", order);

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Give one valid course order.
  • Give the alphabetically earliest valid order.
  • How many jobs can start in the first wave (nothing blocking them)?

You say this first

Repeatedly take indegree-0 nodes from a queue. The peel order is a topological order if and only if the graph is a DAG. I'd dry-run a tiny case first, then say the invariant and the complexity (O(V + E); O(E + V log V) with a heap for lex-smallest time, O(V) space).

Offer the next notch: While queue: u = pop; order.push(u); for v in adj[u]: indegree[v]--; if 0, push v.. Tradeoff: The graph may have cycles and they still want a partial order of the acyclic part — Kahn already gives that (the peeled prefix). Alien Dictionary: build a graph of letter inequalities from adjacent words, then Kahn. Handle invalid prefixes (app after apple).

More notes if you want them

Kahn's algorithm is the interview-friendly topo sort: BFS-shaped, easy to detect cycles, easy to produce the lexicographically smallest order with a min-heap instead of a queue. Course Schedule II, alien dictionary, and 'build order' are this. If they ask for any valid order, a queue is enough.

Use when: Ordering tasks with prerequisites; DP on DAG; unique/lex smallest order questions.

Skip when: The graph may have cycles and they still want a partial order of the acyclic part — Kahn already gives that (the peeled prefix).

Trap: Nodes that never appear in the edge list still need to be in the order.
