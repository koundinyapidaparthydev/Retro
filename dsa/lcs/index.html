Longest Common Subsequence

CORE

The problem they give you

They will not say “Longest Common Subsequence.” They describe this:

Given: Two strings. A common leftover keeps order in both, but letters need not be neighbors.

Find: Length of the longest shared leftover. Contiguous is a different question.

Tiny example: ace vs abcde → ace, length 3. abc vs def → 0.

Name of the tool

dp[i][j] = dp[i-1][j-1]+1 if A[i-1]==B[j-1], else max(dp[i-1][j], dp[i][j-1]). The 2-D string DP template.

Why this tool

LCS is the grid you will redraw for edit distance, shortest common supersequence, and delete-operation counts.

Approach

  1. Allocate (n+1)×(m+1) zeros.
  2. for i=1..n: for j=1..m: if A[i-1]==B[j-1] dp=diag+1 else max(up,left).
  3. Return dp[n][m].

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

match a letter or drop one side

const A = "ace", B = "abcde";
const m = A.length, n = B.length;
const dp = Array.from({ length: m + 1 }, () => Array(n + 1).fill(0));

for (let i = 1; i <= m; i++) {
  for (let j = 1; j <= n; j++) {
    dp[i][j] =
      A[i - 1] === B[j - 1]
        ? dp[i - 1][j - 1] + 1
        : Math.max(dp[i - 1][j], dp[i][j - 1]);
  }
  console.log("after", A[i - 1], dp[i]);
}
console.log("LCS", dp[m][n]);

You say this first

dp[i][j] = dp[i-1][j-1]+1 if A[i-1]==B[j-1], else max(dp[i-1][j], dp[i][j-1]). The 2-D string DP template. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n m) time, O(n m) or O(min(n,m)) space).

Offer the next notch: for i=1..n: for j=1..m: if A[i-1]==B[j-1] dp=diag+1 else max(up,left).. Tradeoff: You need contiguous — longest common substring or sliding window. Draw a 3×3 table on the board for 'ace' vs 'abcde'.

More notes if you want them

LCS is the grid you will redraw for edit distance, shortest common supersequence, and delete-operation counts. If you can fill this table and walk it backward to reconstruct the string, you own a family of interview mediums. Substring (contiguous) is a different recurrence — do not mix them.

Use when: Compare two strings by subsequence; SCS; delete-to-same (n+m-2·LCS).

Skip when: You need contiguous — longest common substring or sliding window.

Trap: Indexing A[i] instead of A[i-1] against a 1-based table.
