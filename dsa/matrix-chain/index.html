Matrix Chain Multiplication

ADV

Definition

Interval DP: dp[i][j] is the min cost to multiply matrices i..j. Try every split k and add the cost of the final multiply.

Why it exists

Matrix chain is the cleanest interval DP.

Approach

  1. for len=2..n: for i=0..n-len: j=i+len-1; dp[i][j]=∞; for k=i..j-1: dp[i][j]=min(..., dp[i][k]+dp[k+1][j]+cost(i,k,j)).
  2. Return dp[0][n-1].
Time O(n³)Space O(n²)

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

try every last split of the chain

const p = [10, 20, 30, 40];
const n = p.length - 1;
const dp = Array.from({ length: n }, () => Array(n).fill(0));

for (let len = 2; len <= n; len++) {
  for (let i = 0; i + len - 1 < n; i++) {
    const j = i + len - 1;
    dp[i][j] = Infinity;
    for (let k = i; k < j; k++) {
      const cost = dp[i][k] + dp[k + 1][j] + p[i] * p[k + 1] * p[j + 1];
      dp[i][j] = Math.min(dp[i][j], cost);
    }
    console.log("A" + i + "..A" + j, dp[i][j]);
  }
}

More notes if you want them

Matrix chain is the cleanest interval DP. Burst balloons, palindrome partitioning, and min-cost tree from leaves are the same 'try every last cut' shape. If you can write the length-outer, split-inner loops here, you can write those interviews. People who nest the loops in the wrong order use unready subintervals.

Use when: Optimal parenthesization; last-cut interval problems.

Skip when: You may merge any pair, not only adjacent — that is Huffman / greedy, not matrix chain.

Trap: Filling by i,j increasing instead of by length — reading uncomputed middles.
