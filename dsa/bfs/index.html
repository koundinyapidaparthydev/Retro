Breadth-First Search

CORE

The problem they give you

They will not say “Breadth-First Search.” They describe this:

Given: A graph or grid. Every step costs the same (one hop).

Find: Fewest hops from start to target. Not a weighted fastest path — just hop count.

Tiny example: A→B, A→C, B→D. Start A, find D. Answer is 2 (A-B-D), not a deep walk.

Name of the tool

Explore a graph like ripples in a pond: everything 1 step away, then 2 steps, then 3. Closest things first.

Why this tool

BFS is the default answer to 'minimum number of moves' on grids, word ladders, and unweighted graphs.

Approach

  1. dist[s] = 0, queue = [s], visited = {s}.
  2. While queue: u = pop front.
  3. For each neighbor v: if not visited, visited.add(v), dist[v] = dist[u]+1, parent[v] = u, push v.

Run it in Java

Left is the snippet. Right is the output — one System.out.println at a time.

shortest hops with a queue

Map<String, List<String>> g = Map.of(
  "A", List.of("B", "C"),
  "B", List.of("D"),
  "C", List.of("E"),
  "D", List.of(),
  "E", List.of()
);
Queue<String> q = new ArrayDeque<>();
Set<String> seen = new HashSet<>();
q.add("A"); seen.add("A");
while (!q.isEmpty()) {
  String node = q.poll();
  System.out.println("visit " + node);
  for (String nxt : g.get(node)) {
    if (seen.add(nxt)) q.add(nxt);
  }
}

You say this first

Unweighted shortest path is BFS. Queue, mark visited on enqueue so the frontier does not explode, store dist or parent. The first time I see the target is the hop-shortest path.

Offer multi-source BFS (several starts at dist 0), grid neighbors, and when I would switch to Dijkstra (weighted) or 0-1 BFS. Reconstruct the path from parent.

More notes if you want them

BFS is the default answer to 'minimum number of moves' on grids, word ladders, and unweighted graphs. Interviewers watch whether you mark visited when you push (so the queue does not explode) and whether you store distance or parent to reconstruct the path. If you DFS these problems you will find a path, not a shortest path.

Use when: Shortest path in unweighted or unit-weight graphs.

Skip when: Positive varying weights — Dijkstra. 0/1 weights — 0-1 BFS. Negative weights — Bellman-Ford.

Trap: Marking on dequeue so the same node enters the queue thousands of times.
