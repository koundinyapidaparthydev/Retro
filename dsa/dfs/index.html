The problem they give you

They will not say “Depth-First Search.” They describe this:

Given: A graph or maze. You may dive down one path before trying the next.

Find: Does a path exist? Visit every node? Not “fewest hops” — that is a different question.

Tiny example: A→B→D dead end, back to A→C. Order might be A, B, D, C.

Name of the tool

Go as deep as you can down one path, then back up and try the next branch — like exploring a maze with one hand on the wall.

Why this tool

DFS is the graph recursion you must write in your sleep: color or mark, recurse on unseen neighbors, optionally record enter/exit times.

Approach

  1. dfs(u): mark u gray.
  2. Iterate all vertices as start points so you cover disconnected graphs.
  3. On a grid, the 'adj' is the four in-bounds unvisited cells with the right value.

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

stack, not recursion

const graph = { A: ["B", "C"], B: ["D"], C: [], D: [] };
const stack = ["A"];
const seen = new Set();

while (stack.length) {
  const node = stack.pop();
  if (seen.has(node)) continue;
  seen.add(node);
  console.log("visit", node);
  for (const nxt of [...graph[node]].reverse()) stack.push(nxt);
}

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Is there a path from start to exit?
  • Number of islands — flood one land mass at a time.

You say this first

Dive along one path until you cannot, then backtrack. The workhorse for connectivity, cycle detection, topological sort, and flood fill. I'd dry-run a tiny case first, then say the invariant and the complexity (O(V + E) time, O(V) colors plus O(V) stack worst case space).

Offer the next notch: Iterate all vertices as start points so you cover disconnected graphs.. Tradeoff: Unweighted shortest path — BFS. For 'can I finish courses,' DFS cycle detection or Kahn — name both.

More notes if you want them

DFS is the graph recursion you must write in your sleep: color or mark, recurse on unseen neighbors, optionally record enter/exit times. Those finishing times are what make topological sort and Kosaraju work. Interviewers use islands, clone graph, and course-schedule as DFS tests. Recursion depth on a 10^5 chain is a real failure mode — know the iterative stack.

Use when: Connectivity, flood fill, cycle detection, topological sort, path existence, SCC pre-pass.

Skip when: Unweighted shortest path — BFS.

Trap: Treating the parent as a back edge in an undirected graph.
