Meeting Rooms

CORE

The problem they give you

They will not say “Meeting Rooms.” They describe this:

Given: Meetings on a timeline. Back-to-back (end == next start) usually share a room.

Find: Can one person attend all? If not, how many rooms so nobody waits?

Tiny example: [(0,30),(5,10),(15,20)] → 2 rooms. One person cannot attend all three.

Name of the tool

Can one person attend all? Sort by start and check adjacent ends. How many rooms? Sweep start/end events or a min-heap of end times — the max depth of the sweep is the answer.

Why this tool

Meeting Rooms I is a sort-and-scan.

Approach

  1. I: sort by start; for i=1..n-1 if starts[i] < ends[i-1] return false.
  2. II heap: sort by start; for each [s,e]: if heap.size && heap.peek<=s pop; push e; ans=max(ans, heap.size).
  3. II sweep: events (s,+1), (e,-1); sort by time then by −1 first; scan.

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • True/false: one room is enough.
  • Minimum rooms (or train platforms).
  • Carpooling: the van has a seat cap; same sweep on pickups and dropoffs.

You say this first

Can one person attend all? Sort by start and check adjacent ends. How many rooms? Sweep start/end events or a min-heap of end times — the max depth of the sweep is the answer. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n log n) time, O(n) space).

Offer the next notch: II heap: sort by start; for each [s,e]: if heap.size && heap.peek<=s pop; push e; ans=max(ans, heap.size).. Tradeoff: Max number of meetings one room can take — that is interval scheduling (earliest finish). Clarify back-to-back (end == start). Usually allowed; sort ends first in the sweep.

More notes if you want them

Meeting Rooms I is a sort-and-scan. Meeting Rooms II is the first 'sweep line / heap of endings' interview and it generalizes to 'minimum platforms,' 'minimum number of arrows,' and CPU interval scheduling. If you allocate a room array and nest, you are O(n²). The heap of current end times is O(n log n) and the story interviewers want.

Use when: Interval overlap tests; min resource count to cover all intervals.

Skip when: Max number of meetings one room can take — that is interval scheduling (earliest finish).

Trap: Comparing unsorted adjacent meetings.
