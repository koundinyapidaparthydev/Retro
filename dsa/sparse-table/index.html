Sparse Table

ADV

Definition

st[k][i] = combine of 2^k elements starting at i. Idempotent range queries (min, max, gcd) become O(1) after O(n log n) build. No updates.

Why it exists

When the array never changes and you need range min (RMQ) in O(1), a sparse table beats a segment tree on query time and is easier than a Cartesian tree.

Approach

  1. Precompute lg[].
  2. query(L,R): k=lg[R-L+1]; return combine(st[k][L], st[k][R-(1<<k)+1]).
Time O(n log n) build, O(1) querySpace O(n log n)

Sparse Table

Precompute lg[]. Build st as above for k=1..LOG, i=0..n-2^k.

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

st[k][i] = min of 2^k starting at i

const A = [4, 2, 3, 7, 1, 5];
const n = A.length;
const LOG = Math.floor(Math.log2(n));
const st = [A.slice()];

for (let k = 1; 1 << k <= n; k++) {
  st[k] = [];
  for (let i = 0; i + (1 << k) <= n; i++) {
    st[k][i] = Math.min(st[k - 1][i], st[k - 1][i + (1 << (k - 1))]);
  }
  console.log("len", 1 << k, st[k]);
}

function rmq(L, R) {
  const k = Math.floor(Math.log2(R - L + 1));
  return Math.min(st[k][L], st[k][R - (1 << k) + 1]);
}

console.log("min[1..4]", rmq(1, 4));
console.log("min[3..5]", rmq(3, 5));

More notes if you want them

When the array never changes and you need range min (RMQ) in O(1), a sparse table beats a segment tree on query time and is easier than a Cartesian tree. LCA reduces to RMQ on an Euler tour — that is why this structure appears next to trees. If you need updates, this table is the wrong tool.

Use when: Static RMQ / range gcd; LCA via Euler tour + RMQ.

Skip when: Updates. Range sums (use prefix). Non-idempotent merges with the O(1) overlap query.

Trap: Using the O(1) overlap query for sum.
