Fibonacci-Style DP

CORE

The problem they give you

They will not say “Fibonacci-Style DP.” They describe this:

Given: A count that depends on the last two answers: ways, rabbits, tiles.

Find: The nth value. Do not recompute the same leftover from scratch.

Tiny example: Ways: 1,1,2,3,5. F(5)=5. Climbing 3 stairs with 1-or-2 is 3 ways: 1+1+1, 1+2, 2+1.

Name of the tool

dp[i] depends on a constant number of previous answers. The teaching family: Fib, climbing stairs, and every 'number of ways to reach i' recurrence.

Why this tool

This is the first DP you should write in an interview.

Approach

  1. Define dp[i] as the answer for size i.
  2. dp[i] = dp[i-1] + dp[i-2] (or the problem's variant).
  3. Iterate i from the first unknown to n.

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • nth Fibonacci.
  • Ways to tile a 2×n board with 1×2 tiles.
  • n is huge; they want it modulo 10^9+7.

You say this first

dp[i] depends on a constant number of previous answers. The teaching family: Fib, climbing stairs, and every 'number of ways to reach i' recurrence. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n); O(log n) with matrix expo time, O(1) rolling; O(n) table space).

Offer the next notch: dp[i] = dp[i-1] + dp[i-2] (or the problem's variant).. Tradeoff: The state needs more than the index (capacity, bitmask) — still DP, not this 1-D template. Start from the last decision: 'to finish n, the last step was 1 or 2.' That sentence is the recurrence.

More notes if you want them

This is the first DP you should write in an interview. The naive recursion is exponential; a 1-D table (or two rolling variables) is linear. Interviewers use it to hear you name overlapping subproblems and optimal substructure before they escalate to knapsack. If you cannot roll the array into O(1) space here, you will struggle later.

Use when: Linear recurrences with a fixed window of dependence.

Skip when: The state needs more than the index (capacity, bitmask) — still DP, not this 1-D template.

Trap: Base cases off by one (n=0 empty vs n=1).
