The problem they give you

They will not say “Catalan Numbers.” They describe this:

Given: n pairs of parentheses, n labeled keys, or a convex polygon.

Find: How many valid structures — matched parentheses, unique BSTs, triangulations.

Tiny example: 3 pairs → 5 strings. 3 BST keys → 5 trees.

Name of the tool

C_0=1, C_{n+1} = Σ C_i C_{n-i}, and C_n = (1/(n+1)) * (2n choose n). They count valid parentheses, BSTs, monotonic paths, and triangulations.

Why this tool

When an interviewer asks 'how many valid parentheses strings / unique BSTs / full binary trees / mountain arrays,' the answer is Catalan.

Approach

  1. DP: dp[0]=1; for n=1..N: dp[n]=Σ dp[i]*dp[n-1-i].
  2. Formula: C(2n,n) * inv(n+1).
  3. Generate: the parentheses DFS, not the formula.

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • How many valid parentheses strings of n pairs?
  • How many unique BSTs on n keys?
  • Ways to triangulate a convex (n+2)-gon.

You say this first

C_0=1, C_{n+1} = Σ C_i C_{n-i}, and C_n = (1/(n+1)) * (2n choose n). They count valid parentheses, BSTs, monotonic paths, and triangulations. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n²) DP; O(n) or better with nCr tables time, O(n) space).

Offer the next notch: Formula: C(2n,n) * inv(n+1).. Tradeoff: Listing for large n — output is huge. Unique BSTs: say Catalan, write the split DP, mention the formula.

More notes if you want them

When an interviewer asks 'how many valid parentheses strings / unique BSTs / full binary trees / mountain arrays,' the answer is Catalan. Generate Parentheses lists them; Unique BSTs counts them. If you only memorize the formula you will miss the DP split. If you only know the DP you will TLE on large n without nCr.

Use when: Count (not list, unless n is small) of the Catalan-structured objects above.

Skip when: Listing for large n — output is huge.

Trap: Off-by-one on C_n vs C_{n+1} (n pairs vs n nodes).
