Group Anagrams

CORE

Definition

Two strings are anagrams if they share a signature. Sort the characters, or count 26 letters, and group words in a map from signature to list.

Why it exists

Group Anagrams is the hashmap-of-lists interview.

Approach

  1. map = Map<string, string[]>.
  2. map.get(key).push(word) after ensuring the list exists.
  3. Return [...map.values()].
Time O(n L log L) with sort keys; O(n L) with counts for alphabet 26Space O(n L) to store the groups

map = Map<string, string[]>. For each word, key = [...word].sort().join('') (or count key).

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

sort letters as the Map key

const words = ["eat", "tea", "tan", "ate"];
const groups = new Map();

for (const w of words) {
  const key = [...w].sort().join("");
  if (!groups.has(key)) groups.set(key, []);
  groups.get(key).push(w);
  console.log(key, groups.get(key));
}
console.log([...groups.values()]);

You say this first

Two strings are anagrams if they share a signature. Sort the characters, or count 26 letters, and group words in a map from signature to list. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n L log L) with sort keys; O(n L) with counts for alphabet 26 time, O(n L) to store the groups space).

Offer the next notch: map.get(key).push(word) after ensuring the list exists.. Tradeoff: You only need to test one pair — sort or count both, no map of groups. Write the sort-key version first in 90 seconds, then mention the count-key upgrade.

More notes if you want them

Group Anagrams is the hashmap-of-lists interview. The only design choice is the key. Sorting each word is O(L log L) and easy. A count tuple is O(L) and faster for short alphabets. Interviewers will ask you which you picked and why, then maybe follow with 'group shifted strings' (another signature).

Use when: Group strings by anagram class or another equivalence given by a signature.

Skip when: You only need to test one pair — sort or count both, no map of groups.

Trap: A weak hash (product of primes) without explaining collisions.
