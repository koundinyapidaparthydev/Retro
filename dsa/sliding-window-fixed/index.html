Fixed Sliding Window

CORE

The problem they give you

They will not say “Fixed Sliding Window.” They describe this:

Given: An array and a window size k. The window must stay contiguous.

Find: The best score of any k neighbors — usually max sum — without rebuilding the window from scratch.

Tiny example: [2, 1, 5, 1, 3, 2], k=3 → [5,1,3]=9 is best. Slide: drop the left, add the right.

Name of the tool

Keep a moving box over a stretch of the array. Slide it instead of rebuilding the box from scratch.

Why this tool

Fixed windows are the interview version of a moving average.

Approach

  1. Compute the aggregate for A[0..k).
  2. For i from k to n-1: add A[i], remove A[i-k], update the best.
  3. For frequency problems, increment the incoming character, decrement the outgoing, and compare the map to the target signature.

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Maximum sum of any k consecutive numbers.
  • Average of each window of size k.

You say this first

Maintain the aggregate of a contiguous block of length k as it slides by one. Add the entering element, drop the leaving one — O(n) instead of O(nk). I'd dry-run a tiny case first, then say the invariant and the complexity (O(n) for O(1) updates; O(n) with a deque for min/max time, O(1) for sums; O(k) or O(Σ) for deques and maps space).

Offer the next notch: For i from k to n-1: add A[i], remove A[i-k], update the best.. Tradeoff: The window size is variable and defined by a constraint (sum ≤ S, at most k distinct). Use a variable window. If they say 'subarray of length k,' do not write a nested loop. Write enter/leave.

More notes if you want them

Fixed windows are the interview version of a moving average. Maximum sum of k consecutive cards, number of anagrams of a length-p pattern, average temperature over a week — if you recompute each window from scratch you are leaving a log of performance on the table and a signal that you missed the pattern. The skill is identifying that every window has the same size so the enter/leave updates are O(1) (or O(1) amortized with a deque for maxima).

Use when: Every query is 'exactly k consecutive elements.'

Skip when: The window size is variable and defined by a constraint (sum ≤ S, at most k distinct). Use a variable window.

Trap: Removing A[i] instead of A[i-k] — off-by-one that fails only on later windows.
