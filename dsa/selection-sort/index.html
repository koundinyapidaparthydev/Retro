Selection Sort

The problem they give you

They will not say “Selection Sort.” They describe this:

Given: An array of numbers. Writes are expensive; reads are cheap.

Find: Sort it with as few writes as you can: for each index, put the right value there once.

Tiny example: [4, 1, 3, 2] → swap 4 with 1 → [1, 4, 3, 2] → next min 2 swaps into index 1 → [1, 2, 3, 4].

Name of the tool

For each index i, find the minimum of the suffix A[i..] and swap it into place. n swaps, always quadratic comparisons.

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • For each seat, find the smallest remaining value and put it there.
  • How many swaps do you need in the worst case?
  • Equal keys get swapped past each other. Does the prompt require original order?

You say this first

For each index i, find the minimum of the suffix A[i..] and swap it into place. n swaps, always quadratic comparisons. I'd dry-run a tiny case first, then say the invariant and the complexity (Θ(n²) comparisons always; O(n) swaps time, O(1) space).

Offer the next notch: Set minIdx = i. For j from i+1 to n-1, if A[j] < A[minIdx], update minIdx.. Tradeoff: Minimal writes versus no adaptivity and no stability. Contrast with insertion sort: selection always scans the whole suffix; insertion stops when the hole finds its place.

More notes if you want them

Selection sort is the algorithm people invent when they sort cards: 'find the smallest, put it first.' Interviews use it to check that you can maintain a growing sorted prefix and that you understand why fewer swaps do not mean a faster sort. It is also the contrast case for heap sort: heap sort is selection sort with a heap accelerating the 'find min' step from O(n) to O(log n).

Use when: When writes are far more expensive than reads and n is small.

Skip when: General-purpose sorting. Insertion sort wins on small or nearly sorted data; n log n sorts win otherwise.

Trap: Starting the min scan at 0 instead of i and destroying the sorted prefix.
