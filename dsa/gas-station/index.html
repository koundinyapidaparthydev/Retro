Gas Station

CORE

The problem they give you

They will not say “Gas Station.” They describe this:

Given: A circular track. Station i gives gas[i] and the drive to the next costs cost[i]. Tank cannot go negative.

Find: A start index that completes the lap, or −1. If total gas < total cost, impossible.

Tiny example: gas [1,2,3,4,5], cost [3,4,5,1,2] → start at index 3. Tank never goes negative from there.

Name of the tool

If total gas ≥ total cost, a circuit exists. The unique start (when unique) is the index after the worst prefix deficit. One pass, O(1) extra.

Why this tool

Gas Station looks like a simulation from every start (O(n²)) and is actually a one-pass greedy.

Approach

  1. total=0, tank=0, start=0.
  2. for i: total += gas[i]-cost[i]; tank += gas[i]-cost[i]; if tank<0: start=i+1; tank=0.
  3. return total>=0 ?

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

if the tank goes negative, start after here

const gas = [1, 2, 3, 4, 5];
const cost = [3, 4, 5, 1, 2];
let tank = 0, total = 0, start = 0;

for (let i = 0; i < gas.length; i++) {
  const d = gas[i] - cost[i];
  tank += d;
  total += d;
  console.log("i", i, "delta", d, "tank", tank);
  if (tank < 0) {
    start = i + 1;
    tank = 0;
    console.log("reset start", start);
  }
}
console.log("start", total >= 0 ? start : -1);

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Return the unique start, or −1.
  • Why a start inside a failed stretch cannot work.
  • Total gas equals total cost. Is a start still guaranteed?

You say this first

If total gas ≥ total cost, a circuit exists. The unique start (when unique) is the index after the worst prefix deficit. One pass, O(1) extra. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n) time, O(1) space).

Offer the next notch: for i: total += gas[i]-cost[i]; tank += gas[i]-cost[i]; if tank<0: start=i+1; tank=0.. Tradeoff: You may refill arbitrarily or stations have capacities — different model. Lead with the O(n²) try-every-start, then the failed-window skip, then the total-sum check.

More notes if you want them

Gas Station looks like a simulation from every start (O(n²)) and is actually a one-pass greedy. The argument: if you fail to reach y from x, no station in (x, y] can reach y either (you arrived at those stations with leftover ≥ 0). So you jump the start to y+1. Combined with a total-sum check, that is the algorithm.

Use when: Circular tour with net gains, unique start when one exists.

Skip when: You may refill arbitrarily or stations have capacities — different model.

Trap: Returning start without checking total < 0.
