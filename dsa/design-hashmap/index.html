Definition

An array of buckets, a hash to a bucket, and a collision strategy (chaining or open addressing). Grow and rehash when the load factor is high.

Why it exists

Design HashMap / HashSet is the 'do you know how the tool works' interview.

Approach

  1. Choose cap (8 or 16), buckets = array of empty lists, size = 0.
  2. idx = hash(key) % cap.
  3. get/remove: same idx, walk, return or splice out.
Time O(1) expected get/put; O(n) worst chain; amortized O(1) with rehashSpace O(n + cap)

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

array of buckets, k % 4

const buckets = [[], [], [], []];

function put(k, v) {
  const i = k % 4;
  const row = buckets[i].find((p) => p[0] === k);
  if (row) row[1] = v;
  else buckets[i].push([k, v]);
  console.log("bucket", i, buckets[i]);
}

put(1, "a");
put(5, "b");
put(2, "c");
console.log("get 5 →", buckets[5 % 4].find((p) => p[0] === 5)[1]);

They ask it like this

  • "Here's an array / graph / string. Can you use HashMap?"
  • "Implement chaining. Mention open addressing. Mention load factor and rehash."
  • "Walk a tiny example, then code."

You say this first

An array of buckets, a hash to a bucket, and a collision strategy (chaining or open addressing). Grow and rehash when the load factor is high. I'd dry-run a tiny case first, then say the invariant and the complexity (O(1) expected get/put; O(n) worst chain; amortized O(1) with rehash time, O(n + cap) space).

Offer the next notch: idx = hash(key) % cap. Walk the list for the key; replace or append. size++. If size/cap > 0.75, rehash to 2×.. Tradeoff: A tiny key universe — a direct array is a perfect hash. Implement chaining. Mention open addressing. Mention load factor and rehash.

More notes if you want them

Design HashMap / HashSet is the 'do you know how the tool works' interview. You must talk about hash functions, load factor, chaining vs probing, and amortized growth. LRU then combines this with a linked list. If you implement a giant array of 10^6 slots and call it a day, they will ask about collisions and memory.

Use when: Implementing the map they forbade you to use, or explaining production hash tables.

Skip when: A tiny key universe — a direct array is a perfect hash.

Trap: No collision handling.
