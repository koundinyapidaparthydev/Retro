Quick Sort

CORE

Definition

Pick a pivot. Put smaller items left, bigger right. Repeat on each side.

Why it exists

Quicksort is the comparison sort you must be able to write on a whiteboard, including the partition.

Approach

  1. If hi - lo <= 1, return.
  2. Choose a pivot (median-of-three, random index, or last element) and move it to a known place.
  3. Partition: all elements < pivot on the left, > pivot on the right, pivot at index p.
Time Θ(n log n) average; Θ(n²) worstSpace O(log n) stack average; O(n) stack if you recurse on the large side first every time

Lomuto partition, pivot sits at p

const a = [3, 7, 1, 4, 2];
function partition(lo, hi) {
  const pivot = a[hi];
  let i = lo;
  for (let j = lo; j < hi; j++) {
    if (a[j] < pivot) { [a[i], a[j]] = [a[j], a[i]]; i++; }
  }
  [a[i], a[hi]] = [a[hi], a[i]];
  console.log("pivot", pivot, "at", i, a.slice());
  return i;
}
function qs(lo, hi) {
  if (lo >= hi) return;
  const p = partition(lo, hi);
  qs(lo, p - 1);
  qs(p + 1, hi);
}
qs(0, a.length - 1);

You say this first

Pick a pivot, partition into lesser and greater, recurse on both sides. Fast average case, fragile worst case, the default in-place comparison sort. I'd dry-run a tiny case first, then say the invariant and the complexity (Θ(n log n) average; Θ(n²) worst time, O(log n) stack average; O(n) stack if you recurse on the large side first every time space).

Offer the next notch: Choose a pivot (median-of-three, random index, or last element) and move it to a known place.. Tradeoff: Best practical constants among comparison sorts versus a quadratic cliff and no stability. Ask which partition they prefer. Implement Lomuto if you want fewer bugs; mention Hoare.

More notes if you want them

Quicksort is the comparison sort you must be able to write on a whiteboard, including the partition. Interviewers use it to test in-place reasoning, two-pointer technique, and whether you understand average versus worst case. Follow-ups are almost automatic: 'what if the array is already sorted?', 'randomize the pivot,' 'three-way partition for duplicates,' 'why does Java use introsort?'

Use when: In-place, cache-friendly sorting of arrays in memory when average speed matters.

Skip when: You need a worst-case n log n guarantee (use heap sort or introsort, or merge sort).

Trap: Recursing on a slice that still includes the pivot and infinite-looping.
