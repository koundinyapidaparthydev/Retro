The problem they give you

They will not say “House Robber.” They describe this:

Given: Houses in a line, each with money. Adjacent houses have linked alarms.

Find: Return the maximum you can rob without robbing two neighbors.

Tiny example: [1, 2, 3, 1] → 4 (1 + 3). [2, 7, 9, 3, 1] → 12.

Name of the tool

LeetCode 198. 1-D DP. medium. Learn the problem statement first, then the pattern.

Why this tool

Approach

Run it in Java

Left is the snippet. Right is the output — one System.out.println at a time.

rob or skip DP

int[] nums = {1, 2, 3, 1};
int prev2 = 0, prev1 = 0;
for (int x : nums) {
  int cur = Math.max(prev1, prev2 + x);
  System.out.println("house " + x + " best=" + cur);
  prev2 = prev1; prev1 = cur;
}
System.out.println("ans " + prev1);
