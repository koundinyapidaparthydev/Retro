Definition

Fill empty cells by trying digits 1–9 that are legal in the row, column, and 3×3 box, then backtrack. Constraint checks decide whether the search lives.

Why it exists

Sudoku is N-Queens with a denser constraint set and a partially filled board.

Approach

  1. Preload occupancy from the given digits.
  2. Try each digit 1–9 that is free in row, col, box.
  3. If dfs returns true, keep the board and return true.
Time O(9^e) worst case for e empties; tiny in practice on real 9×9 puzzlesSpace O(1) extra besides the board and occupancy (recursion depth ≤ e)

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

try a digit, undo on clash

const box = [
  [5, 3, 0],
  [6, 0, 0],
  [0, 9, 8],
];

function ok(r, c, d) {
  for (let i = 0; i < 3; i++) {
    if (box[r][i] === d || box[i][c] === d) return false;
  }
  return true;
}

function solve() {
  for (let r = 0; r < 3; r++) {
    for (let c = 0; c < 3; c++) {
      if (box[r][c] !== 0) continue;
      for (const d of [1, 2, 4, 7]) {
        if (!ok(r, c, d)) {
          console.log("skip", d, "at", r, c);
          continue;
        }
        box[r][c] = d;
        console.log("place", d, "at", r, c);
        if (solve()) return true;
        box[r][c] = 0;
      }
      return false;
    }
  }
  return true;
}

solve();
console.log("done", box.flat());

More notes if you want them

Sudoku is N-Queens with a denser constraint set and a partially filled board. It is a common 'write a solver' interview because the code is structured and the pruning is obvious. Follow-ups: validate a board, count solutions, or pick the empty cell with the fewest candidates (MRV heuristic) to go faster.

Use when: Fill or validate a constraint grid (Sudoku, KenKen-like, Latin squares).

Skip when: The board is guaranteed filled and you only validate.

Trap: Not undoing the box occupancy — the box index formula is the usual bug.
