Aho–Corasick

ADV

The problem they give you

They will not say “Aho–Corasick.” They describe this:

Given: Many keywords and one stream of text.

Find: Every place any keyword appears, in a single pass over the text.

Tiny example: keywords {he, she, his, hers}, text "ushers" → she, he, hers.

Name of the tool

A trie of all patterns plus failure links (KMP on the trie). One scan of the text reports every occurrence of every pattern in O(n + hits + build).

Why this tool

When you have many patterns (a dictionary) and one text, running KMP per pattern is O(n · Σ|p|).

Approach

  1. Insert all patterns into a trie.
  2. BFS: for each node, set fail to fail(parent)'s corresponding child (or root).
  3. Walk the text; at each node emit all outputs on the output chain.

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

trie plus failure links, emit every hit

const words = ["he", "she", "his", "hers"];
const root = { next: {}, fail: null, out: [] };

for (const w of words) {
  let n = root;
  for (const ch of w) {
    n.next[ch] ??= { next: {}, fail: null, out: [] };
    n = n.next[ch];
  }
  n.out.push(w);
}

const q = [];
for (const ch of Object.keys(root.next)) {
  root.next[ch].fail = root;
  q.push(root.next[ch]);
}
while (q.length) {
  const cur = q.shift();
  for (const [ch, nxt] of Object.entries(cur.next)) {
    let f = cur.fail;
    while (f && !f.next[ch]) f = f.fail;
    nxt.fail = (f && f.next[ch]) || root;
    nxt.out = nxt.out.concat(nxt.fail.out);
    q.push(nxt);
  }
}

const text = "ushers";
let node = root;
console.log("scan", text);
for (let i = 0; i < text.length; i++) {
  while (node && !node.next[text[i]]) node = node.fail;
  node = (node && node.next[text[i]]) || root;
  if (node.out.length) console.log("at", i, node.out);
}

You say this first

A trie of all patterns plus failure links (KMP on the trie). One scan of the text reports every occurrence of every pattern in O(n + hits + build). I'd dry-run a tiny case first, then say the invariant and the complexity (O(total pattern chars × Σ + n + number of matches) time, O(total pattern chars × Σ) space).

Offer the next notch: BFS: for each node, set fail to fail(parent)'s corresponding child (or root). Merge output lists.. Tradeoff: One pattern — KMP. If they say 'a million keywords in a stream,' Aho–Corasick is the namedrop. Then discuss build vs scan.

More notes if you want them

When you have many patterns (a dictionary) and one text, running KMP per pattern is O(n · Σ|p|). Aho–Corasick builds an automaton once and streams the text. Word-break-like dictionary matching, virus-signature scanners, and 'replace all keywords' are the story. Interviews rarely require a full implementation; they do require you to name it when Word Search II or multi-pattern comes up at scale.

Use when: Many patterns, one text; dictionary matching; streaming keyword detection.

Skip when: One pattern — KMP.

Trap: Not following failure links on a missing child — you drop later patterns that start mid-window.
