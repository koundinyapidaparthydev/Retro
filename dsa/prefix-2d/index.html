The problem they give you

They will not say “2-D Prefix Sums.” They describe this:

Given: A grid of numbers. You will be asked many rectangle totals: the block from (r1, c1) to (r2, c2).

Find: Answer each rectangle in constant time after a short setup. Do not loop the block every query.

Tiny example: [[1, 2], [3, 4]]. Whole grid sums to 10. The top-left cell alone is 1. The bottom-right 2×1 is 2+4 = 6.

Name of the tool

P[r][c] = sum of the rectangle from (0,0) to (r,c) exclusive. Any submatrix sum is four corners: bottom-right − left − up + up-left.

Why this tool

Range Sum Query 2D (immutable) is the matrix version of prefix sums.

Approach

  1. Allocate P (m+1)×(n+1) zeros.
  2. Write a sum(r1,c1,r2,c2) helper using the four corners.
  3. For submatrices = target: for each pair of horizontal edges, collapse to 1-D and run prefix+map.

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Many rectangle sums on a static matrix.
  • How many sub-rectangles add to a given target?
  • You only have one query. Do you still precompute?

You say this first

P[r][c] = sum of the rectangle from (0,0) to (r,c) exclusive. Any submatrix sum is four corners: bottom-right − left − up + up-left. I'd dry-run a tiny case first, then say the invariant and the complexity (O(mn) build, O(1) query time, O(mn) space).

Offer the next notch: Write a sum(r1,c1,r2,c2) helper using the four corners.. Tradeoff: Single query — just loop the rectangle. Draw a rectangle and shade the three regions you subtract/add. Then write the indices with +1 padding.

More notes if you want them

Range Sum Query 2D (immutable) is the matrix version of prefix sums. Interviewers also hide it in 'number of submatrices that sum to target' (fix two rows, 1-D prefix-map on the compressed column sums). If you loop the four bounds you are O(n^4) or O(n^6). The inclusion-exclusion picture is the whole algorithm.

Use when: Many rectangle sums on a static matrix; submatrix-sum counting.

Skip when: Single query — just loop the rectangle.

Trap: Forgetting the + top-left (double subtraction).
