Bucket Sort

NEXT

Definition

Scatter elements into buckets by value range, sort each bucket, concatenate. Average linear when keys are uniformly spread.

Why it exists

Bucket sort is the floating-point cousin of counting sort.

Approach

  1. Choose b (often n).
  2. For each key x, append it to bucket floor((x - min) / range * b), clamping the max into the last bucket.
  3. Sort each bucket (insertion sort for expected-small buckets).
Time O(n) expected on uniform keys with b = Θ(n); O(n²) worst with insertion sortSpace O(n + b)

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

scatter into n buckets, sort each, concat

const a = [0.42, 0.32, 0.23, 0.52, 0.25];
const n = a.length;
const buckets = Array.from({ length: n }, () => []);
for (const x of a) buckets[Math.floor(x * n)].push(x);
console.log("scatter", buckets);
for (const b of buckets) b.sort((x, y) => x - y);
const out = buckets.flat();
console.log("out", out);

You say this first

Scatter elements into buckets by value range, sort each bucket, concatenate. Average linear when keys are uniformly spread. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n) expected on uniform keys with b = Θ(n); O(n²) worst with insertion sort time, O(n + b) space).

Offer the next notch: For each key x, append it to bucket floor((x - min) / range * b), clamping the max into the last bucket.. Tradeoff: Expected linear time versus a distribution assumption and extra lists. State the uniform assumption out loud. Without it you cannot claim O(n).

More notes if you want them

Bucket sort is the floating-point cousin of counting sort. Interviews mention it when keys are uniformly distributed in [0, 1) or when you need to explain hash-table-like scatter for sorting. It is also a good place to discuss expected versus worst case: one overloaded bucket and you are back to n² if you insertion-sort that bucket.

Use when: Uniform real keys in a known interval.

Skip when: Highly skewed data (power-law keys all land in one bucket).

Trap: Index formula that maps the maximum to bucket b (out of range). Clamp.
