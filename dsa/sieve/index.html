Sieve of Eratosthenes

CORE

The problem they give you

They will not say “Sieve of Eratosthenes.” They describe this:

Given: An integer n (often up to 10^6).

Find: Every prime ≤ n, or the smallest prime factor of every number ≤ n.

Tiny example: n=10 → 2, 3, 5, 7. 1 is not prime.

Name of the tool

Mark multiples of each prime p starting at p². After one pass, unmarked numbers are prime. Linear and segmented sieves exist when N is large.

Why this tool

Count primes, smallest prime factor arrays, and 'prime-related DP' all start with a sieve.

Approach

  1. is[0]=is[1]=false; rest true.
  2. for p=2; p*p<=n; p++: if is[p] for m=p*p; m<=n; m+=p: is[m]=false.
  3. Collect i where is[i].

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • How many primes are there ≤ n?
  • List all primes up to n.
  • Smallest prime factor of every number from 2 to n.

You say this first

Mark multiples of each prime p starting at p². After one pass, unmarked numbers are prime. Linear and segmented sieves exist when N is large. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n log log n) Eratosthenes; O(n) linear sieve time, O(n) space).

Offer the next notch: for p=2; p*p<=n; p++: if is[p] for m=p*p; m<=n; m+=p: is[m]=false.. Tradeoff: A single isPrime on a 64-bit number — Miller–Rabin / deterministic witnesses, not a 10^18 array. Count Primes is this sieve. Do not trial-divide each k ≤ n.

More notes if you want them

Count primes, smallest prime factor arrays, and 'prime-related DP' all start with a sieve. Trial division per query is too slow when you need all primes ≤ n (n=10^6 is the usual cap). Interviewers also use the SPF array (smallest prime factor) as the way to factor many numbers in O(log n) each after an O(n log log n) preprocess.

Use when: All primes ≤ n, many factorizations, prime checks for lots of queries ≤ n.

Skip when: A single isPrime on a 64-bit number — Miller–Rabin / deterministic witnesses, not a 10^18 array.

Trap: Starting marks at 2p instead of p² (still correct, slower).
