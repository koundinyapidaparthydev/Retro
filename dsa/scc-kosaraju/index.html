Strongly Connected Components (Kosaraju)

ADV

The problem they give you

They will not say “Strongly Connected Components (Kosaraju).” They describe this:

Given: One-way streets. Two intersections are in the same cluster if you can drive A→B and B→A.

Find: List the clusters. After you reverse every street, walking from late-finishing corners finds them.

Tiny example: A↔B, A→C. Clusters {A,B} and {C}. C cannot return to A.

Name of the tool

DFS to compute finish order, reverse every edge, DFS again in decreasing finish time. Each tree in the second forest is an SCC.

Why this tool

SCCs compress a directed graph into a DAG of components — the move behind 'eventual safe states,' 2-SAT, and condensing for DP.

Approach

  1. DFS all nodes, push on finish (postorder stack).
  2. Build the reversed adjacency list.
  3. While stack: pop u; if unseen in the reverse graph, dfs and collect that SCC.

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Compress each cluster to one node. What arrows remain?
  • A variable and its opposite in the same cluster — the formula is impossible.
  • How many clusters?

You say this first

DFS to compute finish order, reverse every edge, DFS again in decreasing finish time. Each tree in the second forest is an SCC. I'd dry-run a tiny case first, then say the invariant and the complexity (O(V + E) time, O(V + E) for the reverse graph space).

Offer the next notch: Build the reversed adjacency list.. Tradeoff: Undirected graphs — components are enough; every connected component is 'strong' if you treat edges as bidirectional. Say the three steps slowly. Draw a 2-SCC graph (A→B, B→A, A→C).

More notes if you want them

SCCs compress a directed graph into a DAG of components — the move behind 'eventual safe states,' 2-SAT, and condensing for DP. Kosaraju is the easiest SCC to explain: two DFS passes and a reversed graph. If you only remember one SCC algorithm for interviews, make it this one.

Use when: Directed mutual reachability, 2-SAT, condensing to a DAG.

Skip when: Undirected graphs — components are enough; every connected component is 'strong' if you treat edges as bidirectional.

Trap: Second DFS on the original graph.
