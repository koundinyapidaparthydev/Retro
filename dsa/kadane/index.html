Kadane's Algorithm

CORE

The problem they give you

They will not say “Kadane's Algorithm.” They describe this:

Given: You get a list of numbers. Some can be negative. You must pick one continuous stretch — no skipping cells in the middle.

Find: Which stretch adds up to the biggest total? Return that total (and later, the start and end index).

Tiny example: [-2, 1, -3, 4, -1, 2, 1] → pick [4, -1, 2, 1] = 6. Not [1] and [4,…] separately — they are not one stretch.

Name of the tool

Walk the array once. At each number decide: add it to the streak, or start a new streak here.

Why this tool

Maximum subarray is the first 'DP that looks like a loop' interview.

Approach

  1. cur = ans = A[0].
  2. To recover indices: when you start fresh at i, set start=i; when you beat ans, record [start,i].
  3. Circular: if every A[i]<0 return max(A); else max(kadane, sum-minKadane).

Run it in Java

Left is the snippet. Right is the output — one System.out.println at a time.

max subarray with one pass

int[] a = {-2, 1, -3, 4, -1, 2, 1};
int cur = a[0], ans = a[0];
System.out.println("start cur=" + cur);
for (int i = 1; i < a.length; i++) {
  cur = Math.max(a[i], cur + a[i]);
  ans = Math.max(ans, cur);
  System.out.println("i=" + i + " a=" + a[i] + " cur=" + cur + " ans=" + ans);
}

Whiteboard prompts

These are problem statements. The algorithm name is your answer, not the title of the question.

  • Find the maximum sum of any contiguous subarray.
  • The array can be all negative. What do you return?
  • Now also return the start and end index of that stretch.

You say this first

Maximum subarray sum in one pass: at each index, either extend the previous run or start a new one at i. Track the global best. O(n), O(1) extra. I'd dry-run a tiny case first, then say the invariant and the complexity (O(n) time, O(1) space).

Offer the next notch: To recover indices: when you start fresh at i, set start=i; when you beat ans, record [start,i].. Tradeoff: Non-contiguous — house robber / subset. Empty subarray allowed as 0 — then floor cur at 0 (the other Kadane convention). Ask if an empty subarray is allowed (then ans starts at 0 and you can skip all-negative).

More notes if you want them

Maximum subarray is the first 'DP that looks like a loop' interview. Divide-and-conquer O(n log n) is the textbook alternative and a worse finish. Kadane is the expected linear solution. Follow-ups: return the indices, circular max (max of Kadane vs total-min-subarray), and max product (sign flips, two running values).

Use when: Maximum (or minimum) contiguous sum; circular variant; warmup for max product.

Skip when: Non-contiguous — house robber / subset. Empty subarray allowed as 0 — then floor cur at 0 (the other Kadane convention).

Trap: Initializing ans to 0 and failing all-negative tests.
