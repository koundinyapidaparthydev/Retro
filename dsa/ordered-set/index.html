Ordered Set / Policy-Based Tree

ADV

Definition

A balanced BST that also supports order-statistic queries: find-by-rank and rank-of-key in O(log n). C++ pbds, Java TreeSet plus Fenwick, or a size-augmented treap/splay.

Why it exists

Sliding-window median, 'count of smaller on the left,' and online kth are awkward with a heap (no delete-by-value) and easy with an ordered set that has ranks.

Approach

  1. Compress values if you use a Fenwick: rank is prefix sum of frequencies; kth is binary search on the Fenwick.
  2. Or maintain a balanced tree with sizes (language library / pbds / TreeMap of counts + a Fenwick of those counts).
  3. API: insert, erase, rank, kth, prev/next.
Time O(log n) per op (or O(log U) on a Fenwick of universe U)Space O(n)

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

sorted unique values plus rank / kth

class Ordered {
  constructor() { this.a = []; }
  add(x) {
    const i = this.rank(x);
    if (this.a[i] === x) return;
    this.a.splice(i, 0, x);
    console.log("add", x, this.a);
  }
  rank(x) {
    let lo = 0, hi = this.a.length;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (this.a[mid] < x) lo = mid + 1;
      else hi = mid;
    }
    return lo;
  }
  kth(k) { return this.a[k]; }
}

const s = new Ordered();
s.add(5); s.add(1); s.add(5); s.add(3);
console.log("rank 3", s.rank(3));
console.log("kth 1", s.kth(1));

More notes if you want them

Sliding-window median, 'count of smaller on the left,' and online kth are awkward with a heap (no delete-by-value) and easy with an ordered set that has ranks. Interviews in Java/JS often simulate this with a Fenwick of compressed frequencies or a TreeMap of counts. In C++ you may use __gnu_pbds indexed_set. Knowing the operations is more important than coding a red-black tree from scratch.

Use when: Online order statistics, sliding-window kth, count-smaller online.

Skip when: Only min/max — a heap. Only membership — a hash set.

Trap: TreeSet in Java does not have rank; you cannot get kth in O(log n) without pbds / Fenwick / a custom tree.
