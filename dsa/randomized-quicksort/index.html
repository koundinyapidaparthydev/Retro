Randomized Quicksort

NEXT

Definition

Choose the pivot uniformly at random (or shuffle first) so the n² worst case is vanishingly unlikely instead of input-dependent.

Why it exists

The follow-up to 'quicksort is O(n²) on sorted data' is 'so fix it.' Randomization is the theoretically clean fix: expected time is O(n log n) on ever…

Approach

  1. In partition(lo, hi), pick k uniformly from lo..hi inclusive.
  2. Swap A[k] with A[hi] (Lomuto) or with your Hoare pivot slot.
  3. Run the usual partition and recurse.
Time O(n log n) expected; O(n²) with negligible probabilitySpace O(log n) expected stack

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

swap a random index into the pivot slot

const a = [1, 2, 3, 4, 5];
function partition(lo, hi) {
  const r = lo + ((hi - lo) >> 1); // stand-in for a random index in [lo, hi]
  [a[r], a[hi]] = [a[hi], a[r]];
  const pivot = a[hi];
  let i = lo;
  for (let j = lo; j < hi; j++) {
    if (a[j] < pivot) { [a[i], a[j]] = [a[j], a[i]]; i++; }
  }
  [a[i], a[hi]] = [a[hi], a[i]];
  console.log("rolled", r, "pivot", pivot, "at", i, a.slice());
  return i;
}
function qs(lo, hi) {
  if (lo >= hi) return;
  const p = partition(lo, hi);
  qs(lo, p - 1);
  qs(p + 1, hi);
}
qs(0, a.length - 1);

Offer the next notch: Swap A[k] with A[hi] (Lomuto) or with your Hoare pivot slot.. Tradeoff: Input-independent expected time versus a remaining (tiny) chance of a bad pivot tree. Say 'expected O(n log n) for every input, not average over random arrays.' That distinction is the point.

More notes if you want them

The follow-up to 'quicksort is O(n²) on sorted data' is 'so fix it.' Randomization is the theoretically clean fix: expected time is O(n log n) on every input, including adversarial ones, because the adversary no longer knows your pivot. Interviews use this to see if you distinguish randomized expected time from average-case time over random inputs.

Use when: Any in-place quicksort that might see sorted, reversed, or adversarial input.

Skip when: Environments without a usable RNG where you still need a worst-case bound — use heap sort or median-of-medians.

Trap: Picking a random pivot but then still partitioning around A[0].
