Which two lists point the same way

CORE

The problem they give you

They will not say “Which two lists point the same way.” They describe this:

Given: You have a question vector and many page vectors. Long pages should not win just for being long.

Find: Which pages point the same way as the question?

Tiny example: Query [1, 0]. Page A [0.9, 0.1] beats page B [0, 1]. Direction, not length.

Name of the tool

Cosine similarity asks whether two vectors point the same direction, ignoring how long they are.

Why this tool

This is the usual score for “is this chunk about the question?” Length should not win just because the paragraph is long.

Approach

  1. In JS: dot product, then divide by the two lengths.
  2. Sort descending.
  3. A high score is not “true.” It is “nearby in meaning-space.”
