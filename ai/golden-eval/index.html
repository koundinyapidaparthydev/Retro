The problem they give you

They will not say “A tiny test set you trust.” They describe this:

Given: You changed one line of the prompt. You need to know if the bot got worse before users do.

Find: A short list of questions with the facts you will accept. Pass or fail.

Tiny example: 10 items. Two must be UNKNOWN. A prompt that fails an old pass does not ship.

Name of the tool

A golden eval is a short list of questions with the answers you will accept. You run it on every prompt change.

Why this tool

Applied AI jobs (Unity included) care that you can score a change.

Approach

  1. Store {id, question, mustInclude[], mustNot[], expectUnknown}.
  2. Run the pipeline.
  3. A prompt change that fails an old pass does not ship.

Run it in JavaScript

Left is the snippet. Right is the console — one console.log at a time.

ten rows, pass or fail

const evals = [
  { q: "garage hours", got: "8-20 [1]", pass: true },
  { q: "refunds", got: "UNKNOWN", pass: true },
  { q: "refunds", got: "we refund in 3 days", pass: false },
];
for (const row of evals) console.log(row.q, row.got, row.pass ? "PASS" : "FAIL");

More notes if you want them

Applied AI jobs (Unity included) care that you can score a change. Vibes are not a ship gate.

Use when: Before you demo. Before you tweak the prompt again.

Skip when: One-off playground.

Trap: Thirty vague “good/bad” ratings with no expected fact.
