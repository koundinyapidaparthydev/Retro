Design a unique ID generator

CORE
GooglehotAmazonoftenSnowflake. Google/Twitter lore.

Definition

A service or library that hands out unique, optionally time-sortable 64-bit ids at high QPS without a single SQL sequence.

Why it exists

It looks small and hides clock skew, worker-id allocation, and availability.

Approach

  1. Assign unique worker ids via lease (etcd) or static map.
  2. On mint: if time < last, wait or error; else increment seq or reset on new ms.
  3. Batch ranges if using tickets; persist the high-water mark.
