Redis vs Memcached

CORE

The problem they give you

They will not say “Redis vs Memcached.” They describe this:

Given: You need a cache. Someone said Redis, someone said Memcached, and the use case is not the same.

Find: Pick the tool from the data structure and the failure story, not the logo.

Tiny example: Session blobs vs leaderboards vs locks vs pub/sub, 200k ops/s, eviction under pressure.

Name of the tool

Memcached is a simple distributed memory map. Redis is a data-structure server (and more). Pick based on structures, persistence, and ops — not vibes.

Why this tool

Interviewers still ask this comparison.

Approach

  1. Cache-aside objects: either works; Memcached if you only need GET/SET.
  2. Counters, TTL keys, ZSET, lists: Redis.
  3. Cluster or a fleet with a client hash; watch hot keys.
