Content delivery networks

CORE

Definition

Edge caches that serve static and cacheable HTTP close to users, shield origin, and often terminate TLS.

Why it exists

Images, JS, video segments, and even public API GETs are cheaper and faster at the edge than in your region.

Approach

  1. Separate static hostnames (cdn.example.com) from uncacheable APIs.
  2. Version assets; set long TTL; purge or short-TTL only when you must.
  3. Use signed URLs/cookies for private objects; never a world-readable S3 listing.

More notes if you want them

Images, JS, video segments, and even public API GETs are cheaper and faster at the edge than in your region. A design that puts every byte on the origin will fail the bandwidth estimate. CDNs also change consistency — invalidation is the hard part.

Use when: Any user-generated media, static sites, software downloads, HLS/DASH video.

Skip when: Personalized, authenticated HTML that you cannot Vary correctly.

Trap: Caching Set-Cookie or Authorization responses.
