Definition

Polite, scalable fetch of the public web (or a domain set): frontier queue, politeness per host, parsers, and storage of HTML and links.

Why it exists

Crawlers teach URL frontier, politeness, dedup, and a firehose into storage/index.

Approach

  1. Scheduler dequeues a host's next URL when its token bucket allows.
  2. Fetcher downloads; hasher; if new, store and parse links.
  3. Canonicalize and filter; enqueue unseen URLs with priority.

I'd treat this as a 45-minute HLD. First I lock v1 of web crawler: who uses it, read vs write, latency, what is v2. Polite, scalable fetch of the public web (or a domain set): frontier queue, politeness per host, parsers, and storage of HTML and links.

More notes if you want them

Crawlers teach URL frontier, politeness, dedup, and a firehose into storage/index. It is closer to a data platform than a user API.

Use when: Search engines, SEO tools, site-limited crawlers, link preview fetchers (smaller).

Skip when: Do not crawl the web from one box with a list.

Trap: One queue mixing all hosts — one slow host or one huge host dominates.
