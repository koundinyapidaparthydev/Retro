More notes if you want them

This is a real-time state design with a hard invariant: no conflicting greens. It tests clocks, policies, and fail-safe (all-red / flashing).

Use when: Control systems, safety invariants, timed state machines.

Skip when: City-wide traffic optimization (HLD / OR).

Trap: Two heads toggling independently with Thread.sleep.
