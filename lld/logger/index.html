The problem they give you

They will not say “Logger.” They describe this:

Given: Domain classes call console.log. Tests cannot silence it. Level INFO still concatenates huge strings. PIN is in the line.

Find: Logger port, levels, appenders, formatters. Guarded logging. Null logger for tests. Inject, do not require a global.

Tiny example: Console + file appenders, level INFO. NullLogger in a unit test. Graduate to the async design if logging is the round.

Name of the tool

A small facade: levels, a message, and one or more Appenders. This is the API and object model; the concurrent version is thread-safe logger.

Why this tool

Almost every design logs.

Approach

  1. Logger interface in the domain.
  2. Level threshold.
  3. Appender list.

More notes if you want them

Almost every design logs. A Logger type with a Level and Appender keeps domain classes from calling console.log, and gives you a NullLogger for tests.

Use when: Every non-trivial design's observability port.

Skip when: Replacing exceptions with log-and-continue.

Trap: String concat before level check.
