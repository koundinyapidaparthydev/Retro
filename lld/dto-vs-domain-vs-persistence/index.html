DTO vs domain vs persistence

NEXT

Definition

Three models, three jobs: DTOs travel, domain objects rule, persistence models store. Map between them; do not make one class wear all three hats unless the app is trivial.

Why it exists

A single `User` class with JSON annotations, Hibernate annotations, and `charge()` is how you couple a rewrite of any layer to all layers.

Approach

  1. For a write use case: DTO → command/values → domain → persist model → store.
  2. For a read: store → persist/query → DTO.
  3. Keep mappers in the adapter layer.
