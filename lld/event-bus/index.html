Event bus

Definition

A typed in-process bus: publish(event), subscribe(type, handler). It is a generic mediator. Keep it boring; put rules in handlers, not in the bus.

Why it exists

Event bus is the grown-up Observer.

Approach

  1. Typed subscribe/publish.
  2. Immutable events with ids.
  3. Copy handler list; isolate errors.

More notes if you want them

Event bus is the grown-up Observer. Used well, use cases emit domain events and listeners update projections. Used poorly, it is a stringly-typed god with hidden flows.

Use when: Several independent reactions to a domain fact.

Skip when: A single follow-up action — call it.

Trap: String event names and Map payloads only.
