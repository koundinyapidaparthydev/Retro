Definition

A backpack with a max size. Newest thing you used stays on top. When full, the thing you have not touched in the longest time falls out.

You say this first

I'd keep this in-process. v1 verbs for LRU and LFU cache, then nouns, invariants, one sequence, then I code the heart. A map plus a recency (LRU) or frequency (LFU) structure so get/put are O(1) and eviction is defined. Thread safety is a lock or a concurrent variant around the structure.

Seam for the variant: If they ask threads, lock get/put or document a concurrent sketch.. LRU: simple, bad on scans. LFU: better for long-tail, more code, can stick on old hot keys (use LFU+aging).
