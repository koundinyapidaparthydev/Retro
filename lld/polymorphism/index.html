Polymorphism

CORE

Definition

Call the same operation on different types and let each type run its own implementation — the alternative to sprawling switches.

Why it exists

A design that switches on type in five places will miss the sixth when a new type arrives.

Approach

  1. Identify repeated `if (type == X)` or `instanceof` blocks that choose behavior.
  2. Extract a common method on an interface.
  3. Construct the right implementer at the boundary (factory, parser, config), then pass the interface inward.

More notes if you want them

A design that switches on type in five places will miss the sixth when a new type arrives. Polymorphism moves that branch into the type system so the compiler (or your factory) forces you to handle it once.

Use when: Multiple types share an operation: draw, price, unlock, serialize, notify.

Skip when: A closed set of two cases that will never grow — a local if is clearer.

Trap: Casting after a polymorphic call — the interface was too thin or too wrong.
