Public surface

CORE

The problem they give you

They will not say “Public surface.” They describe this:

Given: Library has twelve public setters and rebalanceInternalHeap(). Tests call them. Controllers setOccupied.

Find: A small verb API from the use cases. Internals stay hidden. Changing a public method is a break.

Tiny example: borrow, return, search. park / unpark / pay. Snapshot DTO instead of a debug getter.

Name of the tool

The public methods of a type are the product. Keep the surface small, named in domain verbs, and stable — everything else is private until a caller must see it.

Why this tool

Interview diagrams that list twenty getters have no design.

Approach

  1. List actors and use cases.
  2. Put them on the type that owns the invariant.
  3. Hide fields, helpers, and collection internals.
