Plugin system

ADV

The problem they give you

They will not say “Plugin system.” They describe this:

Given: A document host switches on plugin.id. The SPI has twenty methods. Plugins reach into private host fields. Disabling one needs a recompile.

Find: Tiny hooks, registry, engine that does not import concretes. Config enables. Isolate failures. Loader may be hardcoded.

Tiny example: SpellCheck and Uppercase plugins. Disable one via config; engine path unchanged. Demo: add a class, register, host untouched.

Name of the tool

A Host defines a small Plugin SPI; a Registry loads and orders plugins; the Engine calls hooks. Adding a feature is a jar/class, not an edit to the host.

Why this tool

This is the coded form of plugin/strategy engines.

Approach

  1. Write 1–2 tiny Hook interfaces.
  2. Registry.register + ordered list.
  3. Engine.run calls hooks.
