Plugin system

ADV

Definition

A Host defines a small Plugin SPI; a Registry loads and orders plugins; the Engine calls hooks. Adding a feature is a jar/class, not an edit to the host.

Why it exists

This is the coded form of plugin/strategy engines.

Approach

  1. Write 1–2 tiny Hook interfaces.
  2. Registry.register + ordered list.
  3. Engine.run calls hooks.
