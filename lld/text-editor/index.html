Text editor (command + memento)

NEXT

Definition

A Buffer holds text and a cursor; Commands mutate it and undo via inverse or Memento; the Invoker keeps undo/redo stacks. Do not put undo inside every key handler ad hoc.

Why it exists

This is the Command + Memento showcase.

Approach

  1. Buffer as the receiver with a small API.
  2. Command.execute/undo.
  3. Editor.invoke pushes history.
Time string insert O(n) naive; gap buffer amortized better; undo O(command size)Space O(document + history)

More notes if you want them

This is the Command + Memento showcase. Interviewers want a buffer API, insert/delete commands, and a bounded history — not a full VS Code.

Use when: Editors, drawing tools, anything with undo.

Skip when: A single input field with OS undo — do not rebuild it.

Trap: Undo that cannot restore deleted text (you did not store it).
