Template Method

NEXT

Definition

Write an algorithm skeleton in a base type and let subclasses fill in the hooks — same steps, different ingredients.

Why it exists

Parsers, game turns, and ETL jobs often share a fixed sequence.

Approach

  1. Write the skeleton as a final/non-overridable method.
  2. Mark varying steps abstract (or small protected hooks).
  3. Keep shared invariant checks in the skeleton.

More notes if you want them

Parsers, game turns, and ETL jobs often share a fixed sequence. Template Method captures that sequence once. The risk is a fragile base class; know when Strategy would be cleaner.

Use when: Fixed pipelines: parse → validate → transform → emit; takeTurn → move → render.

Skip when: The sequence itself varies — Strategy or a list of steps.

Trap: Subclasses calling super.super and depending on hook timing.
