The problem they give you

They will not say “Situation → pattern mapping.” They describe this:

Given: The prompt says weekend price, also SMS, undo that, last seat, test without SQL. Someone reaches for Visitor on the garage.

Find: Map the product sentence to one seam. One pattern, one interface, one concrete. Prefer the smaller fit.

Tiny example: New fee rule → policy object. Also SMS → listener. Undo → command or snapshot. Last seat → atomic reserve. No SQL → port + fake.

Name of the tool

A working table: when you hear a situation in an LLD, which pattern or principle actually fits — and which nearby pattern you should not reach for.

Why this tool

Patterns are a vocabulary for variants.

Approach

  1. Hear the variant in product language ('weekend price', 'also SMS', 'undo that').
  2. Map it to one row of this table — one pattern, one seam.
  3. Put an interface on the diagram; implement one concrete.
